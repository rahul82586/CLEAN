# Terminal Settings

The window of the administrator terminal settings can be opened by pressing the "![Options](images/options_icon.png) Options" button in the ["Services"](User-Interface/Main-Menu/Services.md) menu or using the "Ctrl+O" key combination. All the settings are grouped in three tabs:

  * [Common](Terminal-Settings/Common.md)  
General settings of the administrator terminal.
  * [Support](Terminal-Settings/Support.md)  
The authorization details for contacting the technical support team.
  * [Events](Terminal-Settings/Events.md)  
Setup of notifications about different events in the terminal.
  * [Confirmations](Terminal-Settings/Confirmations.md)  
Configuring confirmation requests for dangerous administration actions.
