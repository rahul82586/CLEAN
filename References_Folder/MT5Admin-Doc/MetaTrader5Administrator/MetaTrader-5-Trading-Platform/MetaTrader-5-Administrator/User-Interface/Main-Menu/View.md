# View

The following commands are available in the "View" menu:

| Command | Description  
| Languages | Select the Administrator terminal interface language. Language change takes effect only after restart.  
| Color Themes | Select a color theme for the Administrator terminal interface: light or dark.  
| Toolbar | Show/hide the [toolbar](../Toolbar.md).  
| Status Bar | Show/hide the [status bar](../Status-Bar.md) at the bottom of the terminal.  
| Split | Select the separator between the left part displaying the server tree with administration sections and the right parts showing the parameters. Move the cursor and fix the desired position of the separator with a single mouse click.  
![Navigate Backward](images/navigate_backward_button.png) | Navigate Backward | Go to the previous viewed page.  
![Navigate Forward](images/navigate_forward_button.png) | Navigate Forward | Undo moving to the previous page.  
![Toolbox](images/toolbox_button.png) | Toolbox | Show/hide the [Instruments](../Toolbox.md) window.
