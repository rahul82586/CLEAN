# File

The "File" menu contains the following commands:

| Command | Description  
![Add Server](images/add_server_button.png) | Add Server | [Add a new server](../../Getting-Started/Add-or-Remove-Servers.md) to be administered through the terminal.  
![Remove Server](images/delete_server_button.png) | Remove Server | [Delete the selected server](../../Getting-Started/Add-or-Remove-Servers.md) from the terminal.  
![Server Properties](images/server_properties_button.png) | Server Properties | Set up connection to the server. The command is inactive if the selected server is currently connected.  
![Connect](images/connect_button.png) | Connect | [Connect to a server](../../Getting-Started/Connect-to-Server.md).  
![Disconnect](images/disconnect_button.png) | Disconnect | Disconnect from the server.  
![Change Password](images/change_password_button.png) | Change Password | [Change password](../../Getting-Started/Change-Password.md) of the current Administrator account.  
![Export](images/export_button.png) | Export | [Export](../../../Platform-Setup/General-Information/ImportExport-Settings.md) platform settings to a JSON file. To export settings of only the selected section, for example, managers, select this section in the tree and execute the command.  
![Import](images/import_button.png) | Import | [Import](../../../Platform-Setup/General-Information/ImportExport-Settings.md) platform settings from a JSON file.  
![Open Data Folder](images/open_data_folder_button.png) | Open Data Folder | Open the folder where the administrator terminal data is stored.  
![Print](images/print_button.png) | Print | Proceed to print the information from the selected tab, for example, accounts or orders.  
![Print Preview](images/print_preview_button.png) | Print Preview | View information before printing. The preview uses the settings of the selected printer. With this command, you can check whether all the required data will be printed.  
![Print Setup](images/print_setup_button.png) | Print Setup | Configure print settings: printer, paper size, page orientation etc.  
![Exit](images/exit_button.png) | Exit | Close the Administrator terminal.
