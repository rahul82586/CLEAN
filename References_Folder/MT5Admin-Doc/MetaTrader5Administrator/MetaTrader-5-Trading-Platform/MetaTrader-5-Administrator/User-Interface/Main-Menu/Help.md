# Help

The following commands are available in the "Help" menu:

| Command | Description  
![Help Topics](images/help_button.png) | Help Topics | Call this Help of the administrator terminal.  
![What's New](images/whatsnew_button.png) | What's New | Link to the [What's New list](https://www.metatrader5.com/en/releasenotes) of the MetaTrader 5 platform's client side.  
| Check Updates | Check and install the latest update of the administrator terminal. The following update options are available for installation:

  * Release version. Such versions are considered to be more stable, as they are subject to longer testing. Such versions are released less frequently.
  * Beta version. It is considered to be less stable. Such versions are released more often, compared to Release versions. Such updates can provide early bug fixes and access to new functions.

This option does not execute the [update of the entire platform](../../../Platform-Setup/Live-Update.md).  
![MQL5.community](images/mql5community_button.png) | MQL5.community | Link to the community of Expert Advisor developers [MQL5.Community](https://www.mql5.com).  
![MetaTrader 5 Platform:](images/metatrader5_button.png) | MetaTrader 5 Platform | Link to the official [MetaTrader 5](https://www.metatrader5.com) platform website.  
![MetaQuotes Ltd](images/metaquotes_button.png) | MetaQuotes Ltd | Link to the official [MetaQuotes](https://www.metaquotes.net/) company website.  
![MetaQuotes Support Center](images/support_button.png) | MetaQuotes Support Center | Link to MetaQuotes' [technical support website](https://support.metaquotes.net "Technical Support").  
![About MetaTrader Administrator](images/about_icon.png) | About MetaTrader Administrator | Show information about the Administrator terminal.
