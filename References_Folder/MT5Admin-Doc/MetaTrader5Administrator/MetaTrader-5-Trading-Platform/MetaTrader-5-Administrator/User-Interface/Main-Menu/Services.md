# Services

The following commands are available in the "Services" menu:

| Command | Description  
![Refresh Configuration](images/refresh_configuration_button.png) | Refresh Configuration | Request configuration changes from the server. If another administrator edited the server configuration during your session, administration inconsistencies may occur. To avoid such situations, it is recommended to run this command from time to time. The command is executed automatically upon login.  
![Restart Server](images/restart_server_button.png) | Restart Server | [Restart server](../../../Platform-Setup/Network-cluster/Restarting-and-Stopping-Servers.md).  
![Deploy Server](images/deploy_icon.png) | Deploy Server | [Deploy](../../../Platform-Installation/Fast-Deployment.md) the selected server in the specified configuration. The command is only available for the servers which have not yet been deployed.  
![Restart Gateways](images/restart_gateways_button.png) | Restart Gateways | Restart all [gateways](../../../Platform-Setup/Gateways.md).  
![Restart Data Feeds](images/restart_datafeeds_button.png) | Restart Data Feeds | Restart all [data feeds](../../../Platform-Setup/Data-Feeds/Restarting.md).  
![Synchronize History](images/synchronize_history_button.png) | Synchronize History | Synchronize [historical data](../../../Platform-Setup/1-Minute-History-Charts.md).  
![Start Live Update](images/start_live_update_icon.png) | Start Live Update | Run platform [update](../../../Platform-Setup/Live-Update.md).  
![Activate License](images/activate_icon.png) | Activate License | [Activate](../../../Platform-Installation/Activation.md) the trading platform. A non-activated platform operates with significant functional limitations.  
![Options](images/options_icon.png) | Options | Open Administrator terminal [settings](../../Terminal-Settings.md).
