# Main Menu

Main menu is located below the title of the program. It contains different commands and functions that can be executed in the terminal. Main menu consists of:

  * [File](Main-Menu/File.md)  
Adding and deleting [servers](../Getting-Started/Add-or-Remove-Servers.md) to administer in the terminal, connecting and disconnecting from them.
  * [Edit](Main-Menu/Edit.md)  
Commands for changing parameters in the different sections of [administration](../../Platform-Setup.md) and the [search](Search.md) system.
  * [View](Main-Menu/View.md)  
Managing elements of the terminal ([toolbars](Toolbar.md), [status bar](Status-Bar.md), ["Toolbox"](Toolbox.md) window) and choosing the interface language.
  * [Services](Main-Menu/Services.md)  
Different service commands.
  * [Help](Main-Menu/Help.md)  
User guide, information about the program and useful links.
