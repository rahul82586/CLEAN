# Hot Keys

Hot keys are keys and their combinations that allow executing various commands without using menus or toolbar. Hot keys execute various functions depending on what terminal interface window is currently active. Some hot keys execute certain functions independent of focus.

## Common Actions in the Terminal

Hot keys | Description  
---|---  
Ctrl+N/Insert | Add an instruction. Depending on the section selected in the tree of servers it executes different commands. For example, in the "Holidays" section it allows to add a holiday; or if the "Symbols" section is chosen, it allows to add a new financial instrument.  
Ctrl+U | Modify selected instruction.  
Ctrl+D/Delete | Delete selected instruction in the current section.  
Ctrl+F | Open the [search](Search.md) window.  
Ctrl+O | Open the window of [options](../Terminal-Settings.md) of the administrator terminal.  
Ctrl+T | Show/hide the Toolbox service window.  
F1 | Open this user guide.  
F3 | Find the next element by the current search request.  
F5 | [Refresh configuration (#refresh)](Main-Menu/Services.md#refresh) of a server.  
  
## Hot Keys in the ["Toolbox"](Toolbox.md) Window

Hot keys | Description  
---|---  
Enter | View a selected [news](Toolbox/News.md), [e-mail (#view)](../../Platform-Setup/Mailbox.md#view) or [search](Toolbox/Search.md) result - depending on the tab selected.  
Insert | Create a new [e-mail (#create)](../../Platform-Setup/Mailbox.md#create) or [news](Toolbox/News.md) \- depending on the tab selected.  
Delete | Delete a selected [e-mail](../../Platform-Setup/Mailbox.md).  
Space | Unwrap a selected [branch of mails](../../Platform-Setup/Mailbox.md).  
R | Show/hide the column of categories of [news](Toolbox/News.md).  
Ctrl+C | Copy the selected journal line of the [terminal](Toolbox/Journal.md) to the clipboard.  
A | Enable/disable auto sizing of columns.  
G | Show/hide grid.
