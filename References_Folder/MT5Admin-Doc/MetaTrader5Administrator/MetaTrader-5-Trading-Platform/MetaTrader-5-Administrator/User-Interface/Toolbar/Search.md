# Search

This part of the toolbar allows to perform the global search of elements through the administrator terminal.

![Search Field](images/search_field.png)

Before starting the search one can specify sections to search in. To do it press the ![Search Settings](images/search_configure_button.png) button, then the list of available sections will be opened. Specify the necessary sections by clicking on the corresponding items. Besides it, using the "Select All" and "Select None" buttons, one can select or unselect all the sections respectively.

Once the necessary settings are made, it is necessary to type the desired word or phrase in the field to the left and press the ![Find](images/search_button.png) button. Also, using the ![Select the previous request](images/downarrow_button.png) button, one can choose one of the previous search requests.

  * In the ["Accounts"](../../../Platform-Setup/Accounts.md), ["Orders"](../../../Platform-Setup/Orders.md) and ["Deals"](../../../Platform-Setup/Deals.md) sections the search is performed only by the entries that are currently displayed in the list.


  * You can search by [serial numbers of SSL certificates (#security)](../../../Platform-Setup/Accounts/Editing-Account.md#security) issued to clients for extended authorization.


  * The results of the global search are displayed at the ["Search"](../Toolbox/Search.md) tab of the "Toolbox" window".
