# Symbol Settings

The symbol setting window appears when a symbol is [added (#symbols-manage)](../Symbols.md#symbols-manage) or [modified (#symbols-manage)](../Symbols.md#symbols-manage). The window contains the following tabs:

  * [Common](Symbol-Settings/Common.md)
  * [Currency](Symbol-Settings/Currency.md)
  * [Quotes](Symbol-Settings/Quotes.md)
  * [Trade](Symbol-Settings/Trade.md)
  * [Futures](Symbol-Settings/Futures.md)
  * [Options](Symbol-Settings/Options.md)
  * [Bonds](Symbol-Settings/Bonds.md)
  * [Execution](Symbol-Settings/Execution.md)
  * [Margin](Symbol-Settings/Margin.md)
  * [Margin Rates](Symbol-Settings/Margin-Rates.md)
  * [Swaps](Symbol-Settings/Swaps.md)
  * [Sessions](Symbol-Settings/Sessions.md)
