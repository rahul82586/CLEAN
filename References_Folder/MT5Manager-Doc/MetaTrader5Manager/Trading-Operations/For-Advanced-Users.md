# For Advanced Users

This section is intended for experienced users. It describes some specific trading features available in the platform:

  * [Margin Calculation: Basic](For-Advanced-Users/Margin-Calculation-Basic.md) — basic margin calculation formulas for all types of symbols.
  * [Margin Calculation: Retail Forex, CFD, Futures — Netting](For-Advanced-Users/Margin-Calculation-Retail-Forex-CFD-Futures-—-Netting.md) — margin calculation for the over-the-counter market with the netting position accounting system.
  * [Margin Calculation: Retail Forex, CFD, Futures — Hedging](For-Advanced-Users/Margin-Calculation-Retail-Forex-CFD-Futures-—-Hedging.md) — margin calculation for the over-the-counter market with the hedging position accounting system.
  * [Margin Calculation: Stock Exchange](For-Advanced-Users/Margin-Calculation-Stock-Exchange.md) — terminology and margin calculation specifics for exchange instruments on a discount basis set by a broker.
  * [Spreads](For-Advanced-Users/Spreads.md) — margin can be charged on preferential basis in case trading positions are in spread relative to each other. The spread trading is defined as the presence of the oppositely directed positions of correlated symbols. 
  * [Collateral Instruments](For-Advanced-Users/Collateral-Symbols.md) — the platform supports a special type of non-tradable instruments, which can be used as client's assets to provide the required margin for open positions of other instruments.
