# Main Menu (#main-menu)

The main menu contains various commands to control the manager terminal and work in it, user's guide, info about the program, as well as links to useful resources.

<a id="file"></a>
## File (#file)

| Command | Description  
![Connect](images/connect_icon.png) | Connect | [Connect](../MetaTrader-5-Manager/Connecting-to-the-Server.md) to the server.  
![Disconnect](images/disconnect_icon.png) | Disconnect | Disconnect from the server.  
![Start Dealing](images/start_dealing_icon.png) | Start Dealing | Start accepting and processing trade requests coming from clients. You are automatically moved to the [Dealer](../Dealing-and-Risk-Management/Dealing.md) tab.  
![Stop Dealing](images/stop_dealing_icon.png) | Stop Dealing | Switch to "offline" mode and no longer accept clients' trade requests.  
![New Account](images/new_account_icon.png) | New Account | [New account](../Clients-and-Trading-Accounts/Creation-of-Accounts.md).  
![Export...](images/export_icon.png) | Export... | [Export](../MetaTrader-5-Manager/For-Advanced-Users/Data-Export.md) data from a selected section: [Online Users](../Clients-and-Trading-Accounts/Online-Accounts.md), [Accounts](../Clients-and-Trading-Accounts/README.md), [Positions](../Trading-Operations/Working-with-Trading-Positions.md) or [Orders](../Trading-Operations/Working-with-Trading-Orders.md).  
![Open Data Folder](images/open_data_folder_button.png) | Open Data Folder | Open the folder [the Manager terminal data](../MetaTrader-5-Manager/For-Advanced-Users/Files-and-Folders.md) is stored in.  
![Print...](images/print_icon.png) | Print... | Go to printing the information displayed on the selected tab, for example — accounts or orders.  
![Print Preview](images/print_preview_icon.png) | Print Preview | View information before printing. Settings of a selected printer are used for it. Using this command you can check if all the data will be printed correctly before you print them.  
| Print Setup... | Configure print settings — a printer, paper size, page orientation etc.  
| Exit | Close the Manager terminal.  
  
<a id="edit"></a>
## Edit (#edit)

| Command | Description  
![Copy](images/copy_icon.png) | Copy | Copy the selected item to clipboard.  
![Find](images/find_icon.png) | Find | Open the search window. Search in the current section allows you to find items in the selected section (Online Users, Accounts, Orders or Positions). After executing the command, the following window appears: ![Search Window](images/search_window.png) It contains the following parameters:

  * Find what — field to enter a search word or phrase.


  * Direction — search direction from the current cursor position: upwards or downwards. The search is performed from the currently selected element on the tab in a set direction.

  
![Find Next](images/find_next_icon.png) | Find Next | Find the next item for the current search query.  
  
<a id="view"></a>
## View (#view)

| Command | Description  
| Languages | Select the Manager terminal interface language. For the changes to take effect, restart the program.  
| Color Themes | Select a color theme for the terminal interface: light or dark.  
| Toolbar | Show/hide the [toolbar](Toolbar.md).  
| Market Depth | Open the submenu that allows showing windows of the [Depth of Market](../Trading-Operations/Market-Depth.md) for symbols, for which this function is available.  
![Market Watch](images/market_watch_icon.png) | Market Watch | Show/hide the [Market Watch](../Trading-Operations/Market-Watch.md) window.  
![Navigator](images/navigator_icon.png) | Navigator | Show/hide the [Navigator](Navigator.md) window.  
![Margin Call](images/margin_calls_icon.png) | Margin Call | Show/hide the [Margin Call](../Dealing-and-Risk-Management/Accounts-with-Margin-CallStop-Out.md) window.  
![Queue](images/queue_icon.png) | Queue | Show/hide the [Queue](../Dealing-and-Risk-Management/Queue-of-Trade-Requests.md) window.  
![Toolbox](images/toolbox_icon.png) | Toolbox | Show/hide the [Toolbox](Toolbox.md) window.  
![Fullscreen](images/fullscreen_icon.png) | Fullscreen | Enable/disable the full screen mode. As soon as this option is enabled, toolbars and status bar are disabled and all signal windows are closed. Only accounts and trades management area remains on the screen. The repeated execution of the command returns the terminal to the initial appearance.
