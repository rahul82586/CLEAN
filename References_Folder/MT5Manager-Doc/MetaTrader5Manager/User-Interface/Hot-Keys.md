# Hot Keys

Hot keys (key shortcuts) are keys and their combinations, which allow you to quickly execute commands without having to use menus and control panels. They can perform different functions depending on which window of the terminal interface is currently active. Some shortcuts perform certain functions, regardless of focus.

## Common actions in the terminal

Hot keys | Description  
---|---  
Ctrl+N | Open the window of [new account](../Clients-and-Trading-Accounts/Creation-of-Accounts.md) creation.  
Ctrl+M | Show/hide the [Market Watch](../Trading-Operations/Market-Watch.md) window.  
Ctrl+L | Show/hide the [Margin Call](../Dealing-and-Risk-Management/Accounts-with-Margin-CallStop-Out.md) window.  
Ctrl+Q | Show/hide the [Queue](../Dealing-and-Risk-Management/Queue-of-Trade-Requests.md) window.  
Ctrl+U | Show/hide the [Plugins](../Managing-Trade-Server-Settings/Managing-Plugins.md) window.  
Ctrl+T | Show/hide the [Toolbox](Toolbox.md) window.  
Ctrl+O | Open the window of the Manager terminal [configuration](../MetaTrader-5-Manager/Terminal-Settings.md).  
F1 | Call this Help of the Manager terminal.  
F11 | Enable/disable the full screen mode.  
  
## Actions in accounts, orders, and positions windows

Hot keys | Description  
---|---  
Ctrl+P | Go to printing the information displayed on the selected tab, for example — accounts or orders.  
Ctrl+C | Copy a selected item to clipboard.  
Ctrl+F | Open the search window.  
F3 | Find the next item for the current search query.  
  
## Actions in the [Market Watch](../Trading-Operations/Market-Watch.md) window

Hot keys | Description  
---|---  
F4 | Open the [Quotes (#quotes)](../Dealing-and-Risk-Management/Quoting-and-Symbol-Management.md#quotes) window.  
Space/Tab | Switch to a [tick chart (#ticks)](../Trading-Operations/Market-Watch.md#ticks).  
Delete | Delete a selected symbol from the window.  
A | Enable/disable auto sizing of columns.  
G | Show/hide grid.  
  
## Actions in the [Margin Call](../Dealing-and-Risk-Management/Accounts-with-Margin-CallStop-Out.md) and [Queue](../Dealing-and-Risk-Management/Queue-of-Trade-Requests.md) windows

Hot keys | Description  
---|---  
T | Show/hide column headers on Requests tab of the Queue window.  
A | Enable/disable auto sizing of columns.  
G | Show/hide grid.  
H | Show/hide column headers.  
  
## Actions in the [Toolbox](Toolbox.md) window

Hot keys | Description  
---|---  
Enter | View a selected [news (#news)](Toolbox.md#news), [email (#mail)](Toolbox.md#mail), [search (#search)](Toolbox.md#search) result or modify a selected [alert](../Trading-Operations/Trading-Notifications.md), depending on the tab.  
Insert | Create a new [email (#mail)](Toolbox.md#mail), [news (#news)](Toolbox.md#news) or [alert](../Trading-Operations/Trading-Notifications.md), depending on the tab.  
Delete | Delete an [email (#mail)](Toolbox.md#mail) or [alert](../Trading-Operations/Trading-Notifications.md), depending on the tab.  
Space | Expand the [email branch (#mail)](Toolbox.md#mail) or enable/disable an [alert](../Trading-Operations/Trading-Notifications.md), depending on the tab.  
R | Show/hide column of the [news categories (#news)](Toolbox.md#news).  
Ctrl+C | Copy a selected line of the [terminal (#journal)](Toolbox.md#journal) or [dealer (#journal)](../Dealing-and-Risk-Management/Dealing.md#journal) journal to clipboard.  
A | Enable/disable auto sizing of columns.  
G | Show/hide grid.
