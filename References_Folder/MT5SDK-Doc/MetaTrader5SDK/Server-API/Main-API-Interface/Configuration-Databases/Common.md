# Common Configuration

Use the functions described in this section to managing the common platform configuration, as well to subscribe and unsubscribe from events associated with its change.

Function | Purpose  
---|---  
[CommonCreate](Common/Create.md) | Create a common platform configuration object.  
[CommonCreateAllocation](Common/CreateAllocation.md) | Create an account allocation configuration object.  
[CommonCreateAgreement](Common/CreateAgreement.md) | Create an agreement object for an account allocation configuration.  
[CommonSubscribe](Common/Subscribe.md) | Subscribe to events and hooks associated with the common configuration of the platform.  
[CommonUnsubscribe](Common/Unsubscribe.md) | Unsubscribe from events and hooks associated with the common configuration of the platform.  
[CommonGet](Common/Get.md) | Get the common platform configuration.  
[CommonSet](Common/Set.md) | Set the common platform configuration.
