# Configuration of Managers

Functions described in this section allow managing the configurations of managers, as well subscribe and unsubscribe from events associated with their change.

Function | Purpose  
---|---  
[ManagerCreate](Managers/ManagerCreate.md) | Create a manager configuration object.  
[ManagerAccessCreate](Managers/ManagerAccessCreate.md) | Create an object of configuration of an access list by IP addresses for a manager.  
[ManagerReportCreate](Managers/ManagerReportCreate.md) | Create an object for the manager's permission to access the report.  
[ManagerSubscribe](Managers/ManagerSubscribe.md) | Subscribe to events and hooks associated with a manager configuration.  
[ManagerUnsubscribe](Managers/ManagerUnsubscribe.md) | Unsubscribe from events and hooks associated with a manager configuration.  
[ManagerAdd](Managers/ManagerAdd.md) | Add or update a manager configuration.  
[ManagerDelete](Managers/ManagerDelete.md) | Deletes a manager configuration by the index.  
[ManagerShift](Managers/ManagerShift.md) | Change the position of a manager configuration in the list.  
[ManagerTotal](Managers/ManagerTotal.md) | The total number of manager configurations available in the platform.  
[ManagerNext](Managers/ManagerNext.md) | Get a manager configuration with the specified index.  
[ManagerGet](Managers/ManagerGet.md) | Get a manager configuration with the specified login.
