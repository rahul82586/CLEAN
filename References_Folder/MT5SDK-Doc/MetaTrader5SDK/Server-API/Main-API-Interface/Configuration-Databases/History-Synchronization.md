# Configuration of History Synchronization

Functions described in this section allow managing the configurations of history data synchronization, as well subscribe and unsubscribe from events associated with its change.

Function | Purpose  
---|---  
[HistorySyncCreate](History-Synchronization/HistorySyncCreate.md) | Create an object of configuration of price data synchronization.  
[HistorySyncSubscribe](History-Synchronization/HistorySyncSubscribe.md) | Subscribe to events and hooks associated with the configuration of price data synchronization.  
[HistorySyncUnsubscribe](History-Synchronization/HistorySyncUnsubscribe.md) | Unsubscribe from events and hooks associated with the configuration of price data synchronization.  
[HistorySyncAdd](History-Synchronization/HistorySyncAdd.md) | Add or update of a configuration of price data synchronization.  
[HistorySyncDelete](History-Synchronization/HistorySyncDelete.md) | Delete a configuration of price data synchronization by its index.  
[HistorySyncShift](History-Synchronization/HistorySyncShift.md) | Change the position of the configuration of price data synchronization in the list.  
[HistorySyncTotal](History-Synchronization/HistorySyncTotal.md) | The total number of configurations of price data synchronization available in the platform.  
[HistorySyncNext](History-Synchronization/HistorySyncNext.md) | Get a configuration of price data synchronization based on its index.
