# News Database

The MetaTrader 5 Server API provides functions for working with the news database of the platform. Using them you can receive and send news, as well as handle events associated with changes in the news database of the server.

> News functions and interfaces work only on history servers.

The following functions are available for working with news:

Function | Purpose  
---|---  
[NewsCreate](News-Database/NewsCreate.md) | Create an object of a news item.  
[NewsSubscribe](News-Database/NewsSubscribe.md) | Subscribe to events and hooks associated with changes in the news database.  
[NewsUnsubscribe](News-Database/NewsUnsubscribe.md) | Undubscribe from events and hooks associated with changes in the news database.  
[NewsSend](News-Database/NewsSend.md) | Send news.
