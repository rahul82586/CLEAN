# Custom Functions

MetaTrader 5 Server API provides the possibility of extending the protocol for running custom commands on the server. The following functions are provided for this purpose:

Function | Purpose  
---|---  
[CustomSubscribe](Custom-Functions/CustomSubscribe.md) | Subscribe to events and hooks associated with the execution of custom functions.  
[CustomUnsubscribe](Custom-Functions/CustomUnsubscribe.md) | Unsubscribe from events and hooks associated with the execution of custom functions.  
[CustomCreateStream](Custom-Functions/CustomCreateStream.md) | Create an object of a byte stream.  
[CustomCommand](Custom-Functions/CustomCommand.md) | Send a custom command to another server within the cluster.
