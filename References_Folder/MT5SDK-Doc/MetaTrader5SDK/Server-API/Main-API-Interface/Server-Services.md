# Server Services

The MetaTrader 5 Server API provides functions for working with auxiliary services of the server. Using them you can restart the server as well as handle events on the server.

Function | Purpose  
---|---  
[ServerRestart](Server-Services/ServerRestart.md) | Restart the server on which the plugin is running.  
[ServerRestartRemote](Server-Services/ServerRestartRemote.md) | Restart the server with the specified identifier.  
[ServerSubscribe](Server-Services/ServerSubscribe.md) | Subscribe to events associated with server events.  
[ServerUnsubscribe](Server-Services/ServerUnsubscribe.md) | Undubscribe from events associated with server events.
