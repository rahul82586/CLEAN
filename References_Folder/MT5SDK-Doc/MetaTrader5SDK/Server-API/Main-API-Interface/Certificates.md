# Certificates

The MetaTrader 5 Server API allows managing a database of certificates that are used for extended authorization of [users](Users.md) on servers. The following functions are provided for this purpose:

Functions | Purpose  
---|---  
[UserCertCreate](Certificates/UserCertCreate.md) | Create an object of a certificate.  
[UserCertUpdate](Certificates/UserCertUpdate.md) | Add or update a client certificate.  
[UserCertGet](Certificates/UserCertGet.md) | Get the certificate of a client by the login.  
[UserCertDelete](Certificates/UserCertDelete.md) | Reset the user certificate.  
[UserCertConfirm](Certificates/UserCertConfirm.md) | Confirm the user certificate.
