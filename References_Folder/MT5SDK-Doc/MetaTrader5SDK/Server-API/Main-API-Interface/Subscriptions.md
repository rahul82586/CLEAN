# Subscriptions

With the "Subscriptions" service, you can offer additional paid services to traders directly in the client terminals. For example, you can sell subscriptions for high-quality market data from well-known providers, offer personal manager services to assist traders in understanding the basics of trading, deliver one-time services such as position transferring or currency conversion, and much more. For further details, please read the [MetaTrader 5 Administrator Help](https://support.metaquotes.net/en/docs/mt5/platform/administration/subscriptions).

The functions described in this section enable the management of subscriptions on traders' accounts:

Function | Purpose  
---|---  
[SubscriptionCreate](Subscriptions/SubscriptionCreate.md) | Create a subscription object.  
[SubscriptionCreateArray](Subscriptions/SubscriptionCreateArray.md) | Create an object of the subscriptions array.  
[SubscriptionSubscribe](Subscriptions/SubscriptionSubscribe.md) | Subscribe to events and hooks associated with changes in the subscriptions database.  
[SubscriptionUnsubscribe](Subscriptions/SubscriptionUnsubscribe.md) | Unsubscribe from events and hooks associated with changes in the subscriptions database.  
[SubscriptionJoin](Subscriptions/SubscriptionJoin.md) | Add a subscription for a user.  
[SubscriptionCancel](Subscriptions/SubscriptionCancel.md) | Cancel a subscription for a user.  
[SubscriptionExist](Subscriptions/SubscriptionExist.md) | Check if a user has the subscription.  
[SubscriptionAdd](Subscriptions/SubscriptionAdd.md) | Add a user subscription to the server database.  
[SubscriptionUpdate](Subscriptions/SubscriptionUpdate.md) | Edit a user subscription in the server database.  
[SubscriptionDelete](Subscriptions/SubscriptionDelete.md) | Delete a user subscription from the server database.  
[SubscriptionGet](Subscriptions/SubscriptionGet.md) | Get all subscriptions of a user.  
[SubscriptionGetBySubscription](Subscriptions/SubscriptionGetBySubscription.md) | Get a user subscription by the subscription configuration ID.  
[SubscriptionGetByID](Subscriptions/SubscriptionGetByID.md) | Get a subscription by ID.  
[SubscriptionGetByLogins](Subscriptions/SubscriptionGetByLogins.md) | Get subscriptions by a list of logins.  
[SubscriptionHistoryCreate](Subscriptions/SubscriptionHistoryCreate.md) | Create a subscription action object.  
[SubscriptionHistoryCreateArray](Subscriptions/SubscriptionHistoryCreateArray.md) | Create an object of an array of subscription actions.  
[SubscriptionHistorySubscribe](Subscriptions/SubscriptionHistorySubscribe.md) | Subscribe to events and hooks associated with changes in the database of subscription actions.  
[SubscriptionHistoryUnsubscribe](Subscriptions/SubscriptionHistoryUnsubscribe.md) | Unsubscribe from events and hooks associated with changes in the database of subscription actions.  
[SubscriptionHistoryAdd](Subscriptions/SubscriptionHistoryAdd.md) | Add a user subscription action to the server database.  
[SubscriptionHistoryUpdate](Subscriptions/SubscriptionHistoryUpdate.md) | Edit a user subscription action in the server database.  
[SubscriptionHistoryDelete](Subscriptions/SubscriptionHistoryDelete.md) | Delete a user subscription action from the server database.  
[SubscriptionHistoryGet](Subscriptions/SubscriptionHistoryGet.md) | Get user subscription action from the server for the specified date range.  
[SubscriptionHistoryGetByID](Subscriptions/SubscriptionHistoryGetByID.md) | Get a subscription action by ID.  
[SubscriptionHistoryGetByLogins](Subscriptions/SubscriptionHistoryGetByLogins.md) | Get subscription actions by a list of logins.
