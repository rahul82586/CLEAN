# Custom Events Interface IMTCustomSink

The IMTCustomSink interface for handling custom events includes the following methods:

Method | Purpose  
---|---  
[HookManagerCommand](Interface-of-Custom-Events/HookManagerCommand.md) | A hook of an event of execution of a manager's custom command.  
[HookWebAPICommand](Interface-of-Custom-Events/HookWebAPICommand.md) | A hook of an event of execution of a web-client's command.  
[HookPluginCommand](Interface-of-Custom-Events/HookPluginCommand.md) | Hook for the execution of a custom command transmitted by the plugin from another server within the cluster.
