# Price Functions

The SMTMath class contains the following methods for working with the prices:

Method | Purpose  
---|---  
[PriceNormalize](Price-Functions/PriceNormalize.md) | Normalizing the transmitted price to the specified number of decimal places.  
[PriceToInt](Price-Functions/PriceToInt.md) | Converting a price from double to int.  
[PriceToDouble](Price-Functions/PriceToDouble.md) | Converting a price from int to double.
