# SMTFormat

This class is used for formatting strings. It contains the following methods:

Method | Purpose  
---|---  
[FormatError](SMTFormat/FormatError.md) | Converts an error code used in the MetaTrader 5 platform into a text description.  
[FormatDouble](SMTFormat/FormatDouble.md) | Formats a number with a given number of decimal places to a string.  
[FormatMoney](SMTFormat/FormatMoney.md) | Formats a number with a given number of decimal places to a string. It is used to show sums of money with thousands separated.  
[FormatPrice](SMTFormat/FormatPrice.md) | Formats a number into a string. Basic and additional accuracy are separately set for a number. As a rule, is used to format the position price.  
[FormatPrices](SMTFormat/FormatPrices.md) | Formats values of Bid, Ask and Last from a passed structure MTTickShort to a string.  
[FormatVolume](SMTFormat/FormatVolume.md) | Formats volume to a string.  
[FormatVolumeDouble](SMTFormat/FormatVolumeDouble.md) | Formats order volume (double) to a string.  
[FormatVolumeExt](SMTFormat/FormatVolumeExt.md) | Formats extended accuracy volume to a string.  
[FormatSize](SMTFormat/FormatSize.md) | Formats size in units to a string.  
[FormatVolumeOrder](SMTFormat/FormatVolumeOrder.md) | Formats order volume to a string.  
[FormatVolumeExtOrder](SMTFormat/FormatVolumeExtOrder.md) | Formats order volume specified with extended accuracy to a string.  
[FormatSizeOrder](SMTFormat/FormatSizeOrder.md) | Formats order size in units to a string.  
[FormatDateTime](SMTFormat/FormatDateTime.md) | Formats date and time to a string.  
[FormatDateTimeMsc](SMTFormat/FormatDateTimeMsc.md) | Formats date and time into a string with an indication of milliseconds.  
[FormatTime](SMTFormat/FormatTime.md) | Formats time into a string.  
[FormatTimeMsc](SMTFormat/FormatTimeMsc.md) | Formats time into a string with an indication of milliseconds.  
[FormatIP](SMTFormat/FormatIP.md) | Formats an IP address and a port to a string.  
[FormatPositionType](SMTFormat/FormatPositionType.md) | Formats the type of a position in a string with a text description.  
[FormatOrderType](SMTFormat/FormatOrderType.md) | Formats the type of an order in a string with a text description.  
[FormatOrderStatus](SMTFormat/FormatOrderStatus.md) | Formats the state of an order in a string with a text description.  
[FormatOrderTypeFilling](SMTFormat/FormatOrderTypeFilling.md) | Formats order filling type in a string with a text description.  
[FormatOrderTypeTime](SMTFormat/FormatOrderTypeTime.md) | Formats order expiration type in a string with a text description.  
[FormatOrderTypeReason](SMTFormat/FormatOrderTypeReason.md) | Formats the order placing reason in a string with a text description.  
[FormatOrderPrice](SMTFormat/FormatOrderPrice.md) | Formats the order price and its triggering price (if any) in a string with a text description.  
[FormatDealAction](SMTFormat/FormatDealAction.md) | Formats the type of action performed by a deal to a string with a text description.  
[FormatDealEntry](SMTFormat/FormatDealEntry.md) | Formats the type of action performed by a deal relative to a position, to a string with a text description.
