# Enumerations (#enumerations)

The [SMTFormat](../SMTFormat.md) class contains one enumeration:

<a id="constants"></a>
## SMTFormat::constants (#constants)

Constants used in the class methods are enumerated in SMTFormat::constants.

ID | Value | Description  
SIG_DECIMAL | L'.' | A point is always used as a decimal mark, regardless of operating system settings.  
SIG_NEGATIVE | L'-' | To specify negative values "-" is used.  
SIG_THOUSAND | L' ' | To separate thousands in numbers a space is used.  
VOLUME_K | L'K' | Letter "K" is used as an abbreviation for "thousand".  
VOLUME_M | L'M' | Letter "M" is used as an abbreviation for "million".
