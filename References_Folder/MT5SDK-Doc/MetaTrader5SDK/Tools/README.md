# Tools

The MetaTrader 5 API provides a number of functions that help to facilitate a number of operations when writing applications. Additional functions are described in a number of classes included in a single header file MT5APITools.h, which is located in the /Common folder.

The additional functions are described by the following classes:

Class | Description  
---|---  
[SMTFormat](SMTFormat.md) | String formatting functions.  
[SMTMath](SMTMath.md) | The functions of mathematical transformations.  
[SMTSearch](SMTSearch.md) | Sort and search functions.  
[CMTArrayBase](CMTArrayBase.md) | A dynamic array class.  
[CMTStr](CMTStr.md) | A string class.  
[CMTSync](CMTSync.md) | A class of critical section of synchronization between threads.  
[CMTThread](CMTThread.md) | Thread control class.  
[SMTTime](SMTTime.md) | Time conversion class.  
[CMTFile](CMTFile.md) | File operations class.
