# SMTSearch

This class is designed for sorting and searching for elements in data arrays. It contains the following methods:

Method | Purpose  
---|---  
[Insert](SMTSearch/Insert.md) | Insert an element in a pre-sorted array without disturbing the sort order.  
[QuickSort](SMTSearch/QuickSort.md) | Sort an array using the sort function passed.  
[Search](SMTSearch/Search.md) | Search in an array the array element that matches the search key.  
[SearchGreatOrEq](SMTSearch/SearchGreatOrEq.md) | Search in an array the first element greater than or equal to the search key.  
[SearchGreater](SMTSearch/SearchGreater.md) | Search in an array the first element greater than the search key.  
[SearchLessOrEq](SMTSearch/SearchLessOrEq.md) | Search in an array the first element less than or equal to the search key.  
[SearchLess](SMTSearch/SearchLess.md) | Search in an array the first element less than the search key.  
[SearchLeft](SMTSearch/SearchLeft.md) | Search in an array the first element equal to the search key.  
[SearchRight](SMTSearch/SearchRight.md) | Search in an array the last element equal to the search key.
