# CMTStr::Replace

Replace the specified substring in the string object with another substring.
    
    
    void  CMTStr::Replace(
       wchar_t  *findstr,     // Substring to replace
       wchar_t  *repstr       // New substring
       )

### Parameters

***findstr**  
[in] The substring to to replace.

***repstr**  
[in] The substring that will replace the found substring.
