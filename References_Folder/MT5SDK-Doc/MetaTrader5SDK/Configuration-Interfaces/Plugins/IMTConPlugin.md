# IMTConPlugin

The IMTConPlugin class contains methods for getting and changing plugin configurations:

Method | Purpose  
---|---  
[Release](IMTConPlugin/Release.md) | Delete the current object.  
[Assign](IMTConPlugin/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConPlugin/Clear.md) | Clear an object.  
[Name](IMTConPlugin/Name.md) | Get and set the name of a plugin.  
[Server](IMTConPlugin/Server.md) | Get and set the server ID.  
[Module](IMTConPlugin/Module.md) | Get and set the plugin module name.  
[Mode](IMTConPlugin/Mode.md) | Get and set the plugin operation mode.  
[Flags](IMTConPlugin/Flags.md) | Get ans set the plugin operation flags.  
[ParameterAdd](IMTConPlugin/ParameterAdd.md) | Add a plugin parameter.  
[ParameterUpdate](IMTConPlugin/ParameterUpdate.md) | Update the parameter of a plugin in the list.  
[ParameterDelete](IMTConPlugin/ParameterDelete.md) | Delete a plugin parameter by the index.  
[ParameterClear](IMTConPlugin/ParameterClear.md) | Clear the list of plugin parameters.  
[ParameterShift](IMTConPlugin/ParameterShift.md) | Change the position of a plugin parameter in the list.  
[ParameterTotal](IMTConPlugin/ParameterTotal.md) | Get the number of plugin parameters.  
[ParameterNext](IMTConPlugin/ParameterNext.md) | Get the plugin parameters by the index.  
[ParameterGet](IMTConPlugin/ParameterGet.md) | Get the plugin parameter by the name.  
  
The IMTConPlugin class contains the following enumerations:

Enumeration | Purpose  
---|---  
[EnPluginMode (#enpluginmode)](IMTConPlugin/Enumerations.md#enpluginmode) | Plugin operation mode.  
[EnPluginFlags (#enpluginflags)](IMTConPlugin/Enumerations.md#enpluginflags) | Plugin operation flags.
