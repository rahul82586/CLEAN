# IMTConPluginSink

The IMTConPluginSink class contains handlers of events of plugin configurations changes:

Method | Purpose  
---|---  
[OnPluginAdd](IMTConPluginSink/OnPluginAdd.md) | A handler of the event of adding a new plugin configuration.  
[OnPluginUpdate](IMTConPluginSink/OnPluginUpdate.md) | A handler of the event of updating a plugin configuration.  
[OnPluginDelete](IMTConPluginSink/OnPluginDelete.md) | A handler of the event of removing a plugin configuration.  
[OnPluginSync](IMTConPluginSink/OnPluginSync.md) | A handler of the event of synchronization of plugin configuration.
