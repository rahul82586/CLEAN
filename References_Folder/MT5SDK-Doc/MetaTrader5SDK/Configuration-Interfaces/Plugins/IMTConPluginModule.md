# IMTConPluginModule

The IMTConPluginModule class contains methods for getting and changing parameters of plugin modules:

Method | Purpose  
---|---  
[Release](IMTConPluginModule/Release.md) | Delete the current object.  
[Assign](IMTConPluginModule/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConPluginModule/Clear.md) | Clear an object.  
[Name](IMTConPluginModule/Name.md) | Get the plugin name, which is inserted by default to a configuration when selecting this module.  
[Vendor](IMTConPluginModule/Vendor.md) | Get the name of the plugin module provider.  
[Description](IMTConPluginModule/Description.md) | Get the description of a plugin module.  
[Module](IMTConPluginModule/Module.md) | Get the name of the plugin module file.  
[Server](IMTConPluginModule/Server.md) | Get the ID of the server.  
[Version](IMTConPluginModule/Version.md) | Get the version of a plugin module.  
[VersionAPI](IMTConPluginModule/VersionAPI.md) | Get the version of the Server API.  
[ParameterTotal](IMTConPluginModule/ParameterTotal.md) | It returns the number of parameters of a plugin module.  
[ParameterNext](IMTConPluginModule/ParameterNext.md) | Get the plugin module parameters by the index.  
[ParameterGet](IMTConPluginModule/ParameterGet.md) | Get the plugin module parameter by the name.
