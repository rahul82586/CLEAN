# IMTConVPSRule

The IMTConVPSRule class contains methods for obtaining and changing rules in Sponsored VPS settings:

Method | Purpose  
---|---  
[Release](IMTConVPSRule/IMTConRule-Release.md) | Delete the current object.  
[Assign](IMTConVPSRule/IMTConRule-Assign.md) | Assign the passed object to the current one.  
[Clear](IMTConVPSRule/IMTConRule-Clear.md) | Clear an object.  
[Enabled](IMTConVPSRule/IMTConRule-Enabled.md) | Get the state of the VPS allocation rule.  
[Name](IMTConVPSRule/IMTConRule-Name.md) | Get the name of the VPS allocation rule.  
[ConditionAdd](IMTConVPSRule/IMTConRule-ConditionAdd.md) | Add a condition to the VPS allocation rule.  
[ConditionUpdate](IMTConVPSRule/IMTConRule-ConditionUpdate.md) | Edit a condition in the VPS allocation rule.  
[ConditionDelete](IMTConVPSRule/IMTConRule-ConditionDelete.md) | Delete a condition from the VPS allocation rule.  
[ConditionClear](IMTConVPSRule/IMTConRule-ConditionClear.md) | Clear the list of conditions in the VPS allocation rule.  
[ConditionShift](IMTConVPSRule/IMTConRule-ConditionShift.md) | Move a condition in the list in the VPS allocation rule.  
[ConditionTotal](IMTConVPSRule/IMTConRule-ConditionTotal.md) | Get the number of conditions in the VPS allocation rule.  
[ConditionNext](IMTConVPSRule/IMTConRule-ConditionNext.md) | Get a condition in the VPS allocation rule by index.
