# IMTConVPS

The IMTConVPS class contains methods for obtaining and changing Sponsored VPS settings:

Method | Purpose  
---|---  
[Release](IMTConVPS/IMTCon-Release.md) | Delete the current object.  
[Assign](IMTConVPS/IMTCon-Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConVPS/IMTCon-Clear.md) | Clear an object.  
[Flags](IMTConVPS/IMTCon-Flags.md) | Get and set additional Sponsored VPS settings.  
[MQL5Login](IMTConVPS/IMTCon-MQL5Login.md) | Get and set the MQL5 account login used for Sponsored VPS. The method is obsolete and is no longer used.  
[MQL5Password](IMTConVPS/IMTCon-MQL5Password.md) | Get and set the MQL5 account password used for Sponsored VPS. The method is obsolete and is no longer used.  
[RuleAdd](IMTConVPS/IMTCon-RuleAdd.md) | Add a VPS allocation rule.  
[RuleUpdate](IMTConVPS/IMTCon-RuleUpdate.md) | Edit a VPS allocation rule.  
[RuleDelete](IMTConVPS/IMTCon-RuleDelete.md) | Delete a VPS allocation rule.  
[RuleClear](IMTConVPS/IMTCon-RuleClear.md) | Clear the list of VPS allocation rules.  
[RuleShift](IMTConVPS/IMTCon-RuleShift.md) | Move the VPS allocation rule in the list.  
[RuleTotal](IMTConVPS/IMTCon-RuleTotal.md) | Get the number of VPS allocation rules.  
[RuleNext](IMTConVPS/IMTCon-RuleNext.md) | Getting the VPS allocation rule by index in the list.  
[GroupAdd](IMTConVPS/IMTCon-GroupAdd.md) | Add a group of accounts in which the Sponsored VPS is allowed. The method is obsolete and is no longer used.  
[GroupUpdate](IMTConVPS/IMTCon-GroupUpdate.md) | Change a group of accounts in which the Sponsored VPS is allowed. The method is obsolete and is no longer used.  
[GroupDelete](IMTConVPS/IMTCon-GroupDelete.md) | Remove a group of accounts from the list of groups in which the Sponsored VPS is allowed. The method is obsolete and is no longer used.  
[GroupClear](IMTConVPS/IMTCon-GroupClear.md) | Clear the list of groups in which the Sponsored VPS is allowed. The method is obsolete and is no longer used.  
[GroupShift](IMTConVPS/IMTCon-GroupShift.md) | Move an entry in the list of groups in which the Sponsored VPS is allowed. The method is obsolete and is no longer used.  
[GroupTotal](IMTConVPS/IMTCon-GroupTotal.md) | Get the number of groups in which the Sponsored VPS is allowed. The method is obsolete and is no longer used.  
[GroupNext](IMTConVPS/IMTCon-GroupNext.md) | Get the group in which the Sponsored VPS is allowed by its index in the list. The method is obsolete and is no longer used.  
  
The IMTConVPS class contains the following enumerations:

Enumeration | Description  
---|---  
[EnFlags (#enflags)](IMTConVPS/IMTCon-Enumerations.md#enflags) | Sponsored VPS settings flags.
