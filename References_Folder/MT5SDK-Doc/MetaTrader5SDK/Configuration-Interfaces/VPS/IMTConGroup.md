# IMTConVPSGroup

The IMTConVPS class contains the methods for getting and changing the list of groups the VPS sponsorship is allowed for:

Method | Purpose  
---|---  
[Release](IMTConVPSGroup/IMTConGroup-Release.md) | Delete the current object.  
[Assign](IMTConVPSGroup/IMTConGroup-Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConVPSGroup/IMTConGroup-Clear.md) | Clear an object.  
[Group](IMTConVPSGroup/IMTConGroup-Group.md) | Get and set a group of accounts the VPS sponsorship is allowed for.  
[MinBalance](IMTConVPSGroup/IMTConGroup-MinBalance.md) | Get and set the minimum balance a trader should have on the account to be able to use the sponsored VPS.  
[InactiveDays](IMTConVPSGroup/IMTConGroup-InactiveDays.md) | Get and set a trader inactivity period, after which the sponsored hosting is automatically canceled.
