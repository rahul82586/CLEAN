# IMTConVPSCondition

The IMTConVPSCondition class contains methods for working with conditions in VPS allocation rules.

Method | Purpose  
---|---  
[Release](IMTConVPSCondition/IMTConCondition-Release.md) | Delete the current object.  
[Assign](IMTConVPSCondition/IMTConCondition-Assign.md) | Assign the passed object to the current one.  
[Clear](IMTConVPSCondition/IMTConCondition-Clear.md) | Clear an object.  
[Condition](IMTConVPSCondition/IMTConCondition-Condition.md) | Get and set the condition type for the VPS allocation rule.  
[Rule](IMTConVPSCondition/IMTConCondition-Rule.md) | Get and set a method for comparing a condition with the specified value.  
[ValueType](IMTConVPSCondition/IMTConCondition-ValueType.md) | Get the type of the condition value in the VPS allocation rule.  
[ValueInt](IMTConVPSCondition/IMTConCondition-ValueInt.md) | Get and set a condition value of the INT type.  
[ValueUInt](IMTConVPSCondition/IMTConCondition-ValueUInt.md) | Get and set a condition value of the UINT type.  
[ValueDouble](IMTConVPSCondition/IMTConCondition-ValueDouble.md) | Get and set a condition value of the double type.  
[ValueString](IMTConVPSCondition/IMTConCondition-ValueString.md) | Get and set a condition value of the string type.  
[ValueColor](IMTConVPSCondition/IMTConCondition-ValueColor.md) | Get and set a condition value of the colorref type.  
[ValueMoney](IMTConVPSCondition/IMTConCondition-ValueMoney.md) | Get and set a condition value that expresses the amount of money.  
[ValueDatetime](IMTConVPSCondition/IMTConCondition-ValueDatetime.md) | Get and set a condition value that expresses date and time.  
[ValueLeverage](IMTConVPSCondition/IMTConCondition-ValueLeverage.md) | Get and set a condition value that expresses the leverage.  
[ValueBool](IMTConVPSCondition/IMTConCondition-ValueBool.md) | Get and set a condition value of the bool type.  
[ValueTime](IMTConVPSCondition/IMTConCondition-ValueTime.md) | Get and set a condition value that expresses the time.  
[ValueDate](IMTConVPSCondition/IMTConCondition-ValueDate.md) | Get a condition value expressing a date.  
[ValuePercent](IMTConVPSCondition/IMTConCondition-ValuePercent.md) | Get a condition value expressing a percentage.  
[ValueLanguage](IMTConVPSCondition/IMTConCondition-ValueLanguage.md) | Get a condition value expressing the language.
