# IMTConKYCGroup

The IMTConKYCGroup method contains classes for getting and changing group settings in KYC providers:

Method | Purpose  
---|---  
[Release](IMTConKYCGroup/IMTConGroup-Release.md) | Delete the current object.  
[Assign](IMTConKYCGroup/IMTConGroup-Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConKYCGroup/IMTConGroup-Clear.md) | Clear an object.  
[Group](IMTConKYCGroup/IMTConGroup-Group.md) | Get and set the group of accounts for which the KYC provider is used.
