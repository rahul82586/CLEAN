# IMTConKYCCountry

The IMTConKYCCountry class contains methods for getting and editing country settings in the KYC provider:

Method | Purpose  
---|---  
[Release](IMTConKYCCountry/IMTConCountry-Release.md) | Delete the current object.  
[Assign](IMTConKYCCountry/IMTConCountry-Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConKYCCountry/IMTConCountry-Clear.md) | Clear an object.  
[CountryCode](IMTConKYCCountry/IMTConCountry-CountryCode.md) | Get and set the country.
