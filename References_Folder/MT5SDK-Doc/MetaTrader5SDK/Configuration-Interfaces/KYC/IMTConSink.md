# IMTConKYCSink

The IMTConKYCSink class contains event handlers for KYC provider configuration changes:

Method | Purpose  
---|---  
[OnKYCAdd](IMTConKYCSink/IMTConSink-OnAdd.md) | The event handler for adding a new KYC provider configuration.  
[OnKYCUpdate](IMTConKYCSink/IMTConSink-OnUpdate.md) | The event handler for updating a KYC provider configuration.  
[OnKYCDelete](IMTConKYCSink/IMTConSink-OnDelete.md) | The event handler for deleting a KYC provider configuration.  
[OnKYCSync](IMTConKYCSink/IMTConSink-OnSync.md) | The event handler for synchronizing KYC provider configurations.
