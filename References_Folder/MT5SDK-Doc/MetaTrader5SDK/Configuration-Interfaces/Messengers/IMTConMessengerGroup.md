# IMTConMessengerGroup

The IMTConMessengerGroup class contains methods for getting and setting group settings in the messenger:

Method | Purpose  
---|---  
[Release](IMTConMessengerGroup/Release.md) | Delete the current object.  
[Assign](IMTConMessengerGroup/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConMessengerGroup/Clear.md) | Clear an object.  
[Group](IMTConMessengerGroup/Group.md) | Get and set the group of accounts for which the messenger is used.
