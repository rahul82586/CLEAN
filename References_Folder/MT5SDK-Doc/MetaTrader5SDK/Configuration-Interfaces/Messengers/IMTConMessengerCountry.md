# IMTConMessengerCountry

The IMTConMessengerCountry class contains methods for getting and setting country settings in the messenger:

Method | Purpose  
---|---  
[Release](IMTConMessengerCountry/Release.md) | Delete the current object.  
[Assign](IMTConMessengerCountry/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConMessengerCountry/Clear.md) | Clear an object.  
[PhoneCode](IMTConMessengerCountry/PhoneCode.md) | Get and set the country calling code.  
[MessageTemplate](IMTConMessengerCountry/MessageTemplate.md) | Get and set a template for sending messages to users from a given country.
