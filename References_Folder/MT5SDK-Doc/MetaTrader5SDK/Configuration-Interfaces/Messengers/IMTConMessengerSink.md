# IMTConMessengerSink

The IMTConMessengerSink class contains event handlers related to manager configuration changes:

Method | Purpose  
---|---  
[OnMessengerAdd](IMTConMessengerSink/OnMessengerAdd.md) | A handler of the the addition of a new messenger configuration.  
[OnMessengerUpdate](IMTConMessengerSink/OnMessengerUpdate.md) | A handler of the messenger configuration update event.  
[OnMessengerDelete](IMTConMessengerSink/OnMessengerDelete.md) | A handler of the messenger configuration deletion event.  
[OnMessengerSync](IMTConMessengerSink/OnMessengerSync.md) | A handler of the messenger configuration synchronization event.
