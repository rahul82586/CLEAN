# IMTConFundSink

The IMTConFundSink class contains event handlers for fund configuration changes:

Method | Purpose  
---|---  
[OnFundAdd](IMTConFundSink/OnFundAdd.md) | Event handler for adding of a new fund configuration.  
[OnFundUpdate](IMTConFundSink/OnFundUpdate.md) | Event handler for fund configuration update.  
[OnFundSync](IMTConFundSink/OnFundSync.md) | Event handler for fund configuration deletion.  
[OnFundSync](IMTConFundSink/OnFundSync.md) | Event handler for the synchronization of fund configurations.
