# IMTConFundInvestor

The IMTConFundInvestor class methods for getting and changing the list of [fund investors (#investors)](https://support.metaquotes.net/en/docs/mt5/platform/administration/fund_etf#investors):

Method | Purpose  
---|---  
[Release](IMTConFundInvestor/Release.md) | Delete the current object.  
[Assign](IMTConFundInvestor/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConFundInvestor/Clear.md) | Clear an object.  
[Login](IMTConFundInvestor/Login.md) | Get and set the login of the account used by the fund investor.  
[Name](IMTConFundInvestor/Name.md) | Get the name of the fund investor.  
[SharesVolume](IMTConFundInvestor/SharesVolume.md) | Get the investor's share size.
