# IMTConFundAccount

The IMTConFundAccount class contains methods for getting and changing the list of [fund managers (#trade-accounts)](https://support.metaquotes.net/en/docs/mt5/platform/administration/fund_etf#trade-accounts):

Method | Purpose  
---|---  
[Release](IMTConFundAccount/Release.md) | Delete the current object.  
[Assign](IMTConFundAccount/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConFundAccount/Clear.md) | Clear an object.  
[Login](IMTConFundAccount/Login.md) | Get and set the login of the account used by the manager for fund management operations.  
[Name](IMTConFundAccount/Name.md) | Get the name of the fund manager.  
[Balance](IMTConFundAccount/Balance.md) | Get the current balance of the account used for fund management.  
[Equity](IMTConFundAccount/Equity.md) | Get the current equity of the account used for fund management.  
[Currency](IMTConFundAccount/Currency.md) | Get the currency in which manager account balance and equity are specified.  
[CurrencyDigits](IMTConFundAccount/CurrencyDigits.md) | Get the number of decimal places in the manager account balance and equity values.
