# IMTConSubscriptionSink

The IMTConSubscriptionSink class contains event handlers related to subscription configuration changes:

Method | Purpose  
---|---  
[OnSubscriptionCfgAdd](IMTConSubscriptionSink/OnSubscriptionCfgAdd.md) | Event handler for adding a new subscription configuration.  
[OnSubscriptionCfgUpdate](IMTConSubscriptionSink/OnSubscriptionCfgUpdate.md) | Event handler for updating subscription configuration.  
[OnSubscriptionCfgDelete](IMTConSubscriptionSink/OnSubscriptionCfgDelete.md) | Event handler for deleting subscription configuration.  
[OnSubscriptionCfgSync](IMTConSubscriptionSink/OnSubscriptionCfgSync.md) | Event handler for synchronizing subscription configuration.
