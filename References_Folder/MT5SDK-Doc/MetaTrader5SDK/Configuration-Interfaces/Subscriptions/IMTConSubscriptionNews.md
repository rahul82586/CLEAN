# IMTConSubscriptionNews

The IMTConSubscriptionNews class provides method for obtaining and editing [news settings](https://support.metaquotes.net/en/docs/mt5/platform/administration/subscriptions/subscriptions_news) in subscription configurations:

Method | Purpose  
---|---  
[Release](IMTConSubscriptionNews/Release.md) | Delete the current object.  
[Assign](IMTConSubscriptionNews/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConSubscriptionNews/Clear.md) | Clear an object.  
[Category](IMTConSubscriptionNews/Category.md) | Get and set news categories available by subscription.  
[Language](IMTConSubscriptionNews/Language.md) | Get and set the language of news available by subscription.
