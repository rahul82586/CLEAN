# IMTConAutoAction

The IMTConAutoAction class contains methods for working with [actions](https://support.metaquotes.net/en/docs/mt5/platform/administration/automation/automation_action) performed upon the triggering of automation tasks:

Method | Purpose  
---|---  
[Release](IMTConAutoAction/Release.md) | Delete the current object.  
[Assign](IMTConAutoAction/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConAutoAction/Clear.md) | Clear an object.  
[Action](IMTConAutoAction/Action.md) | Get and set the action performed upon the triggering of an automation task.  
[Name](IMTConAutoAction/Name.md) | Get and set the name of the action in the routing task.  
[ParamAdd](IMTConAutoAction/ParamAdd.md) | Add a parameter for an automation task action.  
[ParamUpdate](IMTConAutoAction/ParamUpdate.md) | Change a parameter for an automation task action.  
[ParamDelete](IMTConAutoAction/ParamDelete.md) | Delete a parameter from an automation task action.  
[ParamClear](IMTConAutoAction/ParamClear.md) | Clear the list of all parameters for an automation task action.  
[ParamShift](IMTConAutoAction/ParamShift.md) | Shift a parameter of an automation task action.  
[ParamTotal](IMTConAutoAction/ParamTotal.md) | Get the number of parameters of an automation task action.  
[ParamNext](IMTConAutoAction/ParamNext.md) | Get the action parameter by index.  
  
The IMTConAutoAction class contains the following enumerations:

Enumeration | Purpose  
---|---  
[EnActions (#enactions)](IMTConAutoAction/Enumerations.md#enactions) | The actions performed upon the triggering of automation tasks.
