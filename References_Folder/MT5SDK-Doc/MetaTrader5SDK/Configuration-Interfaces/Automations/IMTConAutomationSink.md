# IMTConAutomationSink

The IMTConAutomationSink class contains handlers of events related to automation configuration changes:

Method | Purpose  
---|---  
[OnAutomationAdd](IMTConAutomationSink/OnAutomationAdd.md) | Event hander for the addition of a new automation configuration.  
[OnAutomationUpdate](IMTConAutomationSink/OnAutomationUpdate.md) | Event hander for the update of an automation configuration.  
[OnAutomationDelete](IMTConAutomationSink/OnAutomationDelete.md) | Event hander for the deletion of an automation configuration.  
[OnAutomationSync](IMTConAutomationSink/OnAutomationSync.md) | Event hander for the synchronization of an automation configuration.
