# IMTConAutoCondition

The IMTConAutoCondition class contains methods for working with automation task [triggering conditions](https://support.metaquotes.net/en/docs/mt5/platform/administration/automation/automation_condition):

Method | Purpose  
---|---  
[Release](IMTConAutoCondition/Release.md) | Delete the current object.  
[Assign](IMTConAutoCondition/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConAutoCondition/Clear.md) | Clear an object.  
[Condition](IMTConAutoCondition/Condition.md) | Get and set the type of an additional condition for a rule.  
[Rule](IMTConAutoCondition/Rule.md) | Get and set a method for comparing a condition with the specified value.  
[OrId](IMTConAutoCondition/OrId.md) | Get and set the identifier for the "OR" condition group.  
[ValueType](IMTConAutoCondition/ValueType.md) | Get the type of value an additional condition for a routing rule.  
[ValueInt](IMTConAutoCondition/ValueInt.md) | Get and set a condition value of the INT type.  
[ValueUInt](IMTConAutoCondition/ValueUInt.md) | Get and set a condition value of the UINT type.  
[ValueDouble](IMTConAutoCondition/ValueDouble.md) | Get and set a condition value of the double type.  
[ValueString](IMTConAutoCondition/ValueString.md) | Get and set a condition value of the string type.  
[ValueColor](IMTConAutoCondition/ValueColor.md) | Get and set a condition value of the colorref type.  
[ValueMoney](IMTConAutoCondition/ValueMoney.md) | Get and set a condition value that expresses the amount of money.  
[ValueVolume](IMTConAutoCondition/ValueVolume.md) | Get and set a condition value that expresses the volume.  
[ValueDatetime](IMTConAutoCondition/ValueDatetime.md) | Get and set a condition value that expresses date and time.  
[ValueLeverage](IMTConAutoCondition/ValueLeverage.md) | Get and set a condition value that expresses the leverage.  
[ValueBool](IMTConAutoCondition/ValueBool.md) | Get and set a condition value of the bool type.  
[ValueTime](IMTConAutoCondition/ValueTime.md) | Get and set and set a condition value that expresses the time.  
[ValueDate](IMTConAutoCondition/ValueDate.md) | Get and set a condition value expressing a date.  
[ValuePercent](IMTConAutoCondition/ValuePercent.md) | Get and set a condition value expressing a percentage.  
[ValueLanguage](IMTConAutoCondition/ValueLanguage.md) | Get and set a condition value expressing the language.  
[ValueServer](IMTConAutoCondition/ValueServer.md) | Get and set the value of a condition expressing server identifier.  
[ValuePositionType](IMTConAutoCondition/ValuePositionType.md) | Get and set a condition value expressing position type.  
[ValueReason](IMTConAutoCondition/ValueReason.md) | Get and set a condition value expressing the reason for a trading operation.  
[ValueDealType](IMTConAutoCondition/ValueDealType.md) | Get and set a condition value expressing the deal type.  
[ValueDealEntry](IMTConAutoCondition/ValueDealEntry.md) | Get and set a condition value expressing deal direction.  
[ValueOrderType](IMTConAutoCondition/ValueOrderType.md) | Get and set a condition value expressing order type.  
[ValueOrderState](IMTConAutoCondition/ValueOrderState.md) | Get and set a condition value expressing order state.
