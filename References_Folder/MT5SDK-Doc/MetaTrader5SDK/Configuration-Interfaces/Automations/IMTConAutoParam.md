# IMTConAutoParam

The IMTConAutoParam class contains methods for working with [the parameters of actions](https://support.metaquotes.net/en/docs/mt5/platform/administration/automation/automation_action) performed upon the triggering of automation tasks:

Method | Purpose  
---|---  
[Release](IMTConAutoParam/Release.md) | Delete the current object.  
[Assign](IMTConAutoParam/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConAutoParam/Clear.md) | Clear an object.  
[Param](IMTConAutoParam/Param.md) | Get and set the automation action parameter type.  
[ValueType](IMTConAutoParam/ValueType.md) | Get the action parameter value type.  
[ValueInt](IMTConAutoParam/ValueInt.md) | Get and set a parameter value of INT type.  
[ValueUInt](IMTConAutoParam/ValueUInt.md) | Get and set a parameter value of UINT type.  
[ValueDouble](IMTConAutoParam/ValueDouble.md) | Get and set a parameter value of double type.  
[ValueString](IMTConAutoParam/ValueString.md) | Get and set a parameter value of the string type.  
[ValueColor](IMTConAutoParam/ValueColor.md) | Get and set a parameter value of the colorref type.  
[ValueMoney](IMTConAutoParam/ValueMoney.md) | Get and set the value of the parameter that expresses the amount of money.  
[ValueVolume](IMTConAutoParam/ValueVolume.md) | Get and set the value of the parameter that expresses the volume.  
[ValueDatetime](IMTConAutoParam/ValueDatetime.md) | Get and set the value of the parameter that expresses date and time.  
[ValueLeverage](IMTConAutoParam/ValueLeverage.md) | Get and set the value of the parameter that expresses the leverage.  
[ValueBool](IMTConAutoParam/ValueBool.md) | Get and set a parameter value of bool type.  
[ValueTime](IMTConAutoParam/ValueTime.md) | Get and set the value of the parameter that expresses the time.  
[ValueDate](IMTConAutoParam/ValueDate.md) | Get and set the value of the parameter that expresses the date.  
[ValuePercent](IMTConAutoParam/ValuePercent.md) | Get and set the value of the parameter that expresses the percentage.  
[ValueLanguage](IMTConAutoParam/ValueLanguage.md) | Get and set the value of the parameter that expresses the language.  
[ValueServer](IMTConAutoParam/ValueServer.md) | Get and set the value of the parameter that expresses the server ID.  
[ValueHTML](IMTConAutoParam/ValueHTML.md) | Get and set the parameter value of type "HTML content".  
  
The IMTConAutoParam class contains the following enumerations:

Enumeration | Purpose  
---|---  
[EnParams (#enparams)](IMTConAutoParam/Enumerations.md#enparams) | Possible parameters of actions performed upon the triggering of automation tasks.  
[EnParamType (#enparamtype)](IMTConAutoParam/Enumerations.md#enparamtype) | Types of parameters.
