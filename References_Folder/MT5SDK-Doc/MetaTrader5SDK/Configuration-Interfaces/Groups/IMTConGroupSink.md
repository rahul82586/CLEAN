# IMTConGroupSink

The IMTConGroupSink class contains the following methods:

Method | Purpose  
---|---  
[OnGroupAdd](IMTConGroupSink/OnGroupAdd.md) | A handler of the event of adding a new group.  
[OnGroupUpdate](IMTConGroupSink/OnGroupUpdate.md) | A handler of the event of updating group settings.  
[OnGroupDelete](IMTConGroupSink/OnGroupDelete.md) | A handler of the event of group removal.  
[OnGroupSync](IMTConGroupSink/OnGroupSync.md) | A handler of the event of groups synchronization.  
[HookGroupAdd](IMTConGroupSink/HookGroupAdd.md) | Hook for the new group addition. Only used in Server API.  
[HookGroupUpdate](IMTConGroupSink/HookGroupUpdate.md) | Hook for the update of group settings. Only used in Server API.  
[HookGroupDelete](IMTConGroupSink/HookGroupDelete.md) | Group deletion hook. Only used in Server API.
