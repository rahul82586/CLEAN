# IMTConServerAddressRange

The IMTConServerAddressRange interface contains methods for configuring ranges of IP addresses. The interface is used for configuring the Anti DDoS Proxy Server component, which enables the use of [external Anti-DDoS service providers](https://support.metaquotes.net/en/docs/mt5/platform/administration/admin_network/network_anti_ddos).

Method | Purpose  
---|---  
[Release](IMTConServerAddressRange/Release.md) | Delete the current object.  
[Assign](IMTConServerAddressRange/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConServerAddressRange/Clear.md) | Clear an object.  
[From](IMTConServerAddressRange/From.md) | Get and set the beginning of the range of IP addresses.  
[To](IMTConServerAddressRange/To.md) | Get and set the end of the range of IP addresses.
