# IMTConServerHistory

The IMTConServerHistory interface contains methods for managing settings that are specific to History Servers.

Method | Purpose  
---|---  
[Release](IMTConServerHistory/Release.md) | Delete the current object.  
[Assign](IMTConServerHistory/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConServerHistory/Clear.md) | Clear an object.  
[DatafeedsTimeout](IMTConServerHistory/DatafeedsTimeout.md) | Get and set timeout of data feeds before switching to other data feeds.  
[NewsMax](IMTConServerHistory/NewsMax.md) | Getting and setting the maximum number of news stored on the history server.
