# IMTConServerRange

The IMTConServerRange interface contains methods for setting the ranges of accounts, orders and deals on trade servers.

Method | Purpose  
---|---  
[Release](IMTConServerRange/Release.md) | Delete the current object.  
[Assign](IMTConServerRange/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConServerRange/Clear.md) | Clear an object.  
[From](IMTConServerRange/From.md) | Get and set the beginning of the range of accounts, orders or deals of a trade server.  
[To](IMTConServerRange/To.md) | Get and set the end of the range of accounts, orders or deals of a trade server.  
[UsedFrom](IMTConServerRange/UsedFrom.md) | Gets the beginning of the range of accounts, orders or deals already used on a trade server.  
[UsedTo](IMTConServerRange/UsedTo.md) | Get the end of the range of accounts, orders or deals already used on a trade server.
