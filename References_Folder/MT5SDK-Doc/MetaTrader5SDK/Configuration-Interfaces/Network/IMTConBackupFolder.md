# IMTConBackupFolder

The IMTConBackupFolder interface contains methods for managing user folder backup settings.

Method | Purpose  
---|---  
[Release](IMTConBackupFolder/Release.md) | Delete the current object.  
[Assign](IMTConBackupFolder/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConBackupFolder/Clear.md) | Clear an object.  
[Folder](IMTConBackupFolder/Folder.md) | Get and set the path to the backed-up user folder.  
[Masks](IMTConBackupFolder/Masks.md) | Get and set a list or a wildcard pattern of files to back up.  
[Filter](IMTConBackupFolder/Filter.md) | Get and set a list or a wildcard pattern of files excluded from backup.  
[Flags](IMTConBackupFolder/Flags.md) | Get and set additional folder backup settings.  
  
The IMTConBackupFolder class contains the following enumerations:

Enumeration | Purpose  
---|---  
[EnBackupFlags (#enbackupflags)](IMTConBackupFolder/Enumerations.md#enbackupflags) | Additional folder backup settings.
