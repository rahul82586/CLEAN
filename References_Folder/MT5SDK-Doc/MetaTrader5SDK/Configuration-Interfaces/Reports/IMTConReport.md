# IMTConReport

The IMTConReport class contains methods for getting and changing configurations of reports:

Method | Purpose  
---|---  
[Release](IMTConReport/Release.md) | Delete the current object.  
[Assign](IMTConReport/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConReport/Clear.md) | Clear an object.  
[Name](IMTConReport/Name.md) | Get and set the name of a report.  
[Server](IMTConReport/Server.md) | Get and set the server ID.  
[Module](IMTConReport/Module.md) | Get and set the name of a report module.  
[Mode](IMTConReport/Mode.md) | Get and set the report operation mode.  
[ParameterAdd](IMTConReport/ParameterAdd.md) | Add a report parameter.  
[ParameterUpdate](IMTConReport/ParameterUpdate.md) | Update the parameter of a report in the list.  
[ParameterDelete](IMTConReport/ParameterDelete.md) | Delete a report parameter by the index.  
[ParameterClear](IMTConReport/ParameterClear.md) | Clear the list of report parameters.  
[ParameterShift](IMTConReport/ParameterShift.md) | Change the position of a report parameter in the list.  
[ParameterTotal](IMTConReport/ParameterTotal.md) | Get the number of report parameters.  
[ParameterNext](IMTConReport/ParameterNext.md) | Get parameters of a report by the index.  
[ParameterGet](IMTConReport/ParameterGet.md) | Get a report parameter by the name.  
  
The IMTConReport class contains the following enumerations:

Enumeration | Description  
---|---  
[EnReportMode (#enreportmode)](IMTConReport/Enumerations.md#enreportmode) | Report operation modes.
