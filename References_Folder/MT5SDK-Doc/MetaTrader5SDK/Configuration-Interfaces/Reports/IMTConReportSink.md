# IMTConReportSink

The IMTConReportSink class contains handlers of events of report configurations changes:

Method | Purpose  
---|---  
[OnReportAdd](IMTConReportSink/OnReportAdd.md) | A handler of the event of adding a new report configuration.  
[OnReportUpdate](IMTConReportSink/OnReportUpdate.md) | A handler of the event of updating a report configuration.  
[OnReportDelete](IMTConReportSink/OnReportDelete.md) | A handler of the event of removing a report configuration.  
[OnReportSync](IMTConReportSink/OnReportSync.md) | A handler of the event of synchronization of report configurations.
