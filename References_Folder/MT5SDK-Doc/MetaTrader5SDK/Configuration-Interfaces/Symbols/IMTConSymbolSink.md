# IMTConSymbolSink

The IMTConSymbolSink class contains the following methods:

Method | Purpose  
---|---  
[OnSymbolAdd](IMTConSymbolSink/OnSymbolAdd.md) | A handler of the event of adding a new symbol.  
[OnSymbolUpdate](IMTConSymbolSink/OnSymbolUpdate.md) | A handler of the event of updating symbol settings.  
[OnSymbolDelete](IMTConSymbolSink/OnSymbolDelete.md) | A handler of the event of symbol removal.  
[OnSymbolSync](IMTConSymbolSink/OnSymbolSync.md) | A handler of the event of symbols synchronization.  
[HookSymbolAdd](IMTConSymbolSink/HookSymbolAdd.md) | Hook for adding of the new symbol. Only used in Server API.  
[HookSymbolUpdate](IMTConSymbolSink/HookSymbolUpdate.md) | Hook for the update of symbol settings. Only used in Server API.  
[HookSymbolDelete](IMTConSymbolSink/HookSymbolDelete.md) | Symbol deletion hook. Only used in Server API.
