# IMTConSpreadSink

IMTConSpreadSink class contains the following methods:

Method | Purpose  
---|---  
[OnSpreadAdd](IMTConSpreadSink/OnSpreadAdd.md) | A handler of the event of adding a new spread configuration.  
[OnSpreadUpdate](IMTConSpreadSink/OnSpreadUpdate.md) | A handler of the event of updating spread settings.  
[OnSpreadDelete](IMTConSpreadSink/OnSpreadDelete.md) | A handler of the event of removing a spread configuration.  
[OnSpreadSync](IMTConSpreadSink/OnSpreadSync.md) | A handler of the event of synchronization of spread configurations.
