# IMTConCommon

The IMTConCommon class contains methods for getting and installing the common platform configuration:

Method | Purpose  
---|---  
[Release](IMTConCommon/IMTCon-Release.md) | Delete the current object.  
[Assign](IMTConCommon/IMTCon-Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConCommon/IMTCon-Clear.md) | Clear an object.  
[Name](IMTConCommon/IMTCon-Name.md) | Get and set the server name.  
[NameFull](IMTConCommon/IMTCon-NameFull.md) | Get the full name of the server.  
[Owner](IMTConCommon/IMTCon-Owner.md) | Get the full name of the owner of the platform.  
[OwnerID](IMTConCommon/IMTCon-OwnerID.md) | Get a short name of the owner of the platform.  
[OwnerHost](IMTConCommon/IMTCon-OwnerHost.md) | Get the host address of the platform owner.  
[OwnerEmail](IMTConCommon/IMTCon-OwnerEmail.md) | Get email address of the owner of the platform.  
[Product](IMTConCommon/IMTCon-Product.md) | Get the full name of the product.  
[ExpirationLicense](IMTConCommon/IMTCon-ExpirationLicense.md) | Get the license expiry date.  
[ExpirationSupport](IMTConCommon/IMTCon-ExpirationSupport.md) | Get the date of technical support expiry.  
[LimitTradeServers](IMTConCommon/IMTCon-LimitTradeServers.md) | Get the maximum number of trade servers.  
[LimitWebServers](IMTConCommon/IMTCon-LimitWebServers.md) | Get the maximum number of web servers.  
[LimitAccounts](IMTConCommon/IMTCon-LimitAccounts.md) | Get the maximum number of accounts that can be opened in the trading platform.  
[LimitDeals](IMTConCommon/IMTCon-LimitDeals.md) | Get the maximum number of deals that can be committed in the trading platform.  
[LimitGroups](IMTConCommon/IMTCon-LimitGroups.md) | Get the maximum number of groups that can be created in the trading platform.  
[LimitSymbols](IMTConCommon/IMTCon-LimitSymbols.md) | Get the maximum number of financial instruments that can be created in the trading platform.  
[LiveUpdateMode](IMTConCommon/IMTCon-LiveUpdateMode.md) | Get and setting the update mode of the components of the trading platform.  
[TotalUsers](IMTConCommon/IMTCon-TotalUsers.md) | Get the total number of client accounts in the entire trading platform.  
[TotalUsersReal](IMTConCommon/IMTCon-TotalUsersReal.md) | Get the total number of real clients in the entire trading platform.  
[TotalDeals](IMTConCommon/IMTCon-TotalDeals.md) | Get the total number of deals executed in the entire trading platform.  
[TotalOrders](IMTConCommon/IMTCon-TotalOrders.md) | Get the total number of active orders placed in the entire trading platform.  
[TotalOrdersHistory](IMTConCommon/IMTCon-TotalOrdersHistory.md) | Get the total number of orders in the history in the entire trading platform.  
[TotalPositions](IMTConCommon/IMTCon-TotalPositions.md) | Get the total number of positions in the entire trading platform.  
[AccountURL](IMTConCommon/IMTCon-AccountURL.md) | Get and set the address a client is redirected to when opening a demo account from the client terminal.  
[AccountDepositURL](IMTConCommon/IMTCon-AccountDepositURL.md) | Get and set the deposit page URL for all accounts in the platform.  
[AccountWithdrawalURL](IMTConCommon/IMTCon-AccountWithdrawalURL.md) | Get and set the withdrawal page URL for all accounts in the platform.  
[AccountAllocationAdd](IMTConCommon/IMTCon-AccountAllocationAdd.md) | Add an account allocation configuration.  
[AccountAllocationUpdate](IMTConCommon/IMTCon-AccountAllocationUpdate.md) | Edit an account allocation configuration.  
[AccountAllocationDelete](IMTConCommon/IMTCon-AccountAllocationDelete.md) | Delete an account allocation configuration.  
[AccountAllocationClear](IMTConCommon/IMTCon-AccountAllocationClear.md) | Clear the list of account allocation configurations.  
[AccountAllocationShift](IMTConCommon/IMTCon-AccountAllocationShift.md) | Move the account allocation configuration in the list.  
[AccountAllocationTotal](IMTConCommon/IMTCon-AccountAllocationTotal.md) | Getting the number of account allocation configurations.  
[AccountAllocationNext](IMTConCommon/IMTCon-AccountAllocationNext.md) | Get the account allocation configuration by index.  
  
The IMTConCommon class contains the following enumerations:

Enumeration | Purpose  
---|---  
[EnUpdateMode](IMTConCommon/IMTCon-Enumerations.md) | Update receiving mode.
