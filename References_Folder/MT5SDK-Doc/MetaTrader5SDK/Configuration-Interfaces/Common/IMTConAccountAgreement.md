# IMTConAccountAgreement

The IMTConAccountAgreement class contains methods for working with the [agreements (#agreement)](https://support.metaquotes.net/ru/docs/mt5/platform/administration/admin_accounts/account_allocation_groups#agreement) which are shown to clients when opening accounts through terminals.

Method | Purpose  
---|---  
[Release](IMTConAccountAgreement/Release.md) | Delete the current object.  
[Assign](IMTConAccountAgreement/Assign.md) | Assign the passed object to the current one.  
[Clear](IMTConAccountAgreement/Clear.md) | Clear an object.  
[CaptionType](IMTConAccountAgreement/CaptionType.md) | Get the agreement type.  
[CaptionCustomText](IMTConAccountAgreement/CaptionCustomText.md) | Get the name of the user agreement.  
[URL](IMTConAccountAgreement/URL.md) | Get the agreement link.  
[Flags](IMTConAccountAgreement/Flags.md) | Get additional agreement settings.  
  
The IMTConAccountAgreement class contains the following enumerations:

Enumeration | Purpose  
---|---  
[EnCaptionType (#encaptiontype)](IMTConAccountAgreement/Enumerations.md#encaptiontype) | Agreement types.  
[EnFlags (#enflags)](IMTConAccountAgreement/Enumerations.md#enflags) | Additional agreement settings.
