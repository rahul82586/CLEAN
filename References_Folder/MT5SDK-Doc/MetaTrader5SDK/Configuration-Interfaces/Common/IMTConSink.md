# IMTConCommonSink

The IMTConCommonSink class contains handlers of event of common configuration change:

Method | Purpose  
---|---  
[OnCommonUpdate](IMTConCommonSink/IMTConSink-OnUpdate.md) | The handler of the event of common configuration update.  
[OnCommonSync](IMTConCommonSink/IMTConSink-OnSync.md) | This method is called by the API to notify that a common configuration has been updated.
