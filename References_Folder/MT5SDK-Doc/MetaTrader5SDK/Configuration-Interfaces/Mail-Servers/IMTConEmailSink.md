# IMTConEmailSink

The IMTConEmailSink class contains event handlers for changes in mail server configurations:

Method | Purpose  
---|---  
[OnEmailAdd](IMTConEmailSink/OnEmailAdd.md) | Handler of the addition of a new mail server configuration.  
[OnEmailUpdate](IMTConEmailSink/OnEmailDelete.md) | Handler of the update of a mail server configuration.  
[OnEmailDelete](IMTConEmailSink/OnEmailDelete.md) | Handler of the deletion of a mail server configuration.  
[OnEmailSync](IMTConEmailSink/OnEmailSync.md) | Handler of the synchronization of mail server configurations.
