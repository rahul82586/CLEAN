# IMTConEmail

The IMTConEmail class contains methods for getting and changing mail server configurations:

Method | Purpose  
---|---  
[Release](IMTConEmail/Release.md) | Delete the current object.  
[Assign](IMTConEmail/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConEmail/Clear.md) | Clear an object.  
[Name](IMTConEmail/Name.md) | Get and set the mail server configuration name.  
[SenderMail](IMTConEmail/SenderMail.md) | Get and set the email address, from which emails will be sent via the mail server configurations.  
[SenderName](IMTConEmail/SenderName.md) | Get and set the sender name in the mail server configuration.  
[Server](IMTConEmail/Server.md) | Get and set the SMTP server address in the mail server configuration.  
[Login](IMTConEmail/Login.md) | Get and set the SMTP login in the mail server configuration.  
[Password](IMTConEmail/Password.md) | Get and set the SMTP password in the mail server configuration.  
[Flags](IMTConEmail/Flags.md) | Get and set additional mail server settings.  
  
The IMTConEmail class contains the following enumerations:

Enumeration | Description  
---|---  
[EnFlags (#enflags)](IMTConEmail/Enumerations.md#enflags) | Mail server configuration flags.
