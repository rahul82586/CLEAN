# IMTConLeverage

The IMTConLeverage class contains methods for retrieving and updating [floating margin](https://support.metaquotes.net/en/docs/mt5/platform/administration/leverages) configurations:

Method | Purpose  
---|---  
[Release](IMTConLeverage/Release.md) | Delete the current object.  
[Assign](IMTConLeverage/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConLeverage/Clear.md) | Clear an object.  
[Name](IMTConLeverage/Name.md) | Get and set the name for the floating margin configuration.  
[RuleAdd](IMTConLeverage/RuleAdd.md) | Add a rule to a floating margin configuration.  
[RuleUpdate](IMTConLeverage/RuleUpdate.md) | Update a rule in a floating margin configuration.  
[RuleDelete](IMTConLeverage/RuleDelete.md) | Delete a rule from a floating margin configuration.  
[RuleClear](IMTConLeverage/RuleClear.md) | Clear the list of rules in a floating margin configuration.  
[RuleShift](IMTConLeverage/RuleShift.md) | Move a rule in a floating margin configuration.  
[RuleTotal](IMTConLeverage/RuleTotal.md) | Get the number of rules in a floating margin configuration.  
[RuleNext](IMTConLeverage/RuleNext.md) | Get a rule from a floating margin configuration by index.  
[RuleGet](IMTConLeverage/RuleGet.md) | Get a rule from a floating margin configuration by name.
