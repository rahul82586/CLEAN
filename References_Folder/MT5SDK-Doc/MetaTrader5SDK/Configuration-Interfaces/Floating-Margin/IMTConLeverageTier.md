# IMTConLeverageTier

The IMTConLeverageTier class contains method for retrieving and modifying levels in a [floating margin](https://support.metaquotes.net/ru/docs/mt5/platform/administration/leverages) rules:

Method | Purpose  
---|---  
[Release](IMTConLeverageTier/Release.md) | Delete the current object.  
[Assign](IMTConLeverageTier/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConLeverageTier/Clear.md) | Clear an object.  
[RangeFrom](IMTConLeverageTier/RangeFrom.md) | Get the minimum range value for a level in a floating margin rule.  
[RangeTo](IMTConLeverageTier/RangeTo.md) | Get the maximum range value for a level in a floating margin rule.  
[MarginRateInitial](IMTConLeverageTier/MarginRateInitial.md) | Get the initial margin rate for a level in a floating margin rule.  
[MarginRateMaintenance](IMTConLeverageTier/MarginRateMaintenance.md) | Get the maintenance margin rate for a level in a floating margin rule.
