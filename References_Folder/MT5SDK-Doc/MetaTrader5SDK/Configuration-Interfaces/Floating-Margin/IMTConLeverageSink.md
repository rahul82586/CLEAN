# IMTConLeverageSink

The IMTConLeverageSink class contains methods for tracking and intercepting event related to changes in [floating margin](https://support.metaquotes.net/ru/docs/mt5/platform/administration/leverages) configurations:

Method | Purpose  
---|---  
[OnLeverageAdd](IMTConLeverageSink/OnLeverageAdd.md) | Handler for the event of adding a new floating margin configuration.  
[OnLeverageUpdate](IMTConLeverageSink/OnLeverageUpdate.md) | Handler for the event of updating a floating margin configuration.  
[OnLeverageDelete](IMTConLeverageSink/OnLeverageDelete.md) | Handler for the event of deleting a floating margin configuration.  
[OnLeverageSync](IMTConLeverageSink/OnLeverageSync.md) | Handler for the event of synchronizing a floating margin configuration.  
[HookLeverageAdd](IMTConLeverageSink/HookLeverageAdd.md) | Hook for adding a new floating margin configuration.  
[HookLeverageUpdate](IMTConLeverageSink/HookLeverageUpdate.md) | Hook for editing a floating margin configuration.  
[HookLeverageDelete](IMTConLeverageSink/HookLeverageDelete.md) | Hook for deleting a floating margin configuration.
