# Funds and ETFs

MetaTrader 5 enables the automation of fund operations. This includes investor and manager operations, investment management, access to charts and reports: For more details, please read the [MetaTrader 5 Administrator Help](https://support.metaquotes.net/en/docs/mt5/platform/administration/fund_etf).

The interfaces described in this section enable the management of fund settings:

  * [IMTConFund](Funds-and-ETF/IMTConFund.md) — methods for getting and changing fund settings.
  * [IMTConFundAccount](Funds-and-ETF/IMTConFundAccount.md) — methods for getting and changing the list of fund managers.
  * [IMTConFundInvestor](Funds-and-ETF/IMTConFundInvestor.md) — methods for getting and changing the list of fund investors.
  * [IMTConFundSink](Funds-and-ETF/IMTConFundSink.md) — event handlers for fund configuration changes.
