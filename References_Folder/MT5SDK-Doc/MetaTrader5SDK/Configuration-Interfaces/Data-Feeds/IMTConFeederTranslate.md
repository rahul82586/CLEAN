# IMTConFeederTranslate

The IMTConFeederTranslate interface contains methods for managing conversion of symbols and quotes received from a data feed.

Method | Purpose  
---|---  
[Release](IMTConFeederTranslate/Release.md) | Get the parameter of the data feed module by name.  
[Assign](IMTConFeederTranslate/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConFeederTranslate/Clear.md) | Clear an object.  
[Source](IMTConFeederTranslate/Source.md) | Get and set the symbol name in the data feed.  
[Symbol](IMTConFeederTranslate/Symbol.md) | Get and set the symbol name in the trading platform.  
[BidMarkup](IMTConFeederTranslate/BidMarkup.md) | Get and set a correction to the Bid price arriving for a symbol from a data feed.  
[AskMarkup](IMTConFeederTranslate/AskMarkup.md) | Get and set a correction to the Ask price arriving for a symbol from a data feed.  
[Digits](IMTConFeederTranslate/Digits.md) | Get the number of digits after the decimal point in the price of the symbol that receives quotes.
