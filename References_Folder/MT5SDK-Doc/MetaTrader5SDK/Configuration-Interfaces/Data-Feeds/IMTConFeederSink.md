# IMTConFeederSink

The IMTConFeederSink interface contains the handlers of events of data feed configuration changes:

Method | Purpose  
---|---  
[OnFeederAdd](IMTConFeederSink/OnFeederAdd.md) | A handler of the event of adding a new data feed configuration.  
[OnFeederUpdate](IMTConFeederSink/OnFeederUpdate.md) | A handler of the event of updating a data feed configuration.  
[OnFeederDelete](IMTConFeederSink/OnFeederDelete.md) | A handler of the event of removing a data feed configuration.  
[OnFeederSync](IMTConFeederSink/OnFeederSync.md) | A handler of the event of synchronization of a data feed configuration.
