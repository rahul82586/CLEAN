# IMTConManagerAccess

The IMTConManagerAccess class contains the following methods:

Method | Purpose  
---|---  
[Release](IMTConManagerAccess/Release.md) | Delete the current object.  
[Assign](IMTConManagerAccess/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConManagerAccess/Clear.md) | Clear an object.  
[From](IMTConManagerAccess/From.md) | Get and set the beginning of the range of IP addresses, from which a manager account can connect.  
[To](IMTConManagerAccess/To.md) | Get and set the end of the range of IP addresses, from which a manager account can connect.
