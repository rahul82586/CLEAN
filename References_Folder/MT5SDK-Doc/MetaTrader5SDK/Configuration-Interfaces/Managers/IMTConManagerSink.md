# IMTConManagerSink

The IMTConManagerSink class contains the following methods:

Method | Purpose  
---|---  
[OnManagerAdd](IMTConManagerSink/OnManagerAdd.md) | A handler of the event of adding a new manager configuration.  
[OnManagerUpdate](IMTConManagerSink/OnManagerUpdate.md) | A handler of the event of updating manager settings.  
[OnManagerDelete](IMTConManagerSink/OnManagerDelete.md) | A handler of the event of removing a manager configuration.  
[OnManagerSync](IMTConManagerSink/OnManagerSync.md) | A handler of the event of synchronization of manager configurations.  
[HookManagerAdd](IMTConManagerSink/HookManagerAdd.md) | Hook for the addition of a new manager configuration. Only used in Server API.  
[HookManagerUpdate](IMTConManagerSink/HookManagerUpdate.md) | Hook for the update of manager settings. Only used in Server API.  
[HookManagerDelete](IMTConManagerSink/HookManagerDelete.md) | Hook for the deletion of a manager configuration. Only used in Server API.
