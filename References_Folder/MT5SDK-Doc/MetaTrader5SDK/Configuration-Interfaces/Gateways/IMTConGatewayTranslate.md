# IMTConGatewayTranslate

The IMTConGatewayTranslate class contains the following methods:

Method | Purpose  
---|---  
[Release](IMTConGatewayTranslate/Release.md) | Delete the current object.  
[Assign](IMTConGatewayTranslate/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTConGatewayTranslate/Clear.md) | Clear an object.  
[Source](IMTConGatewayTranslate/Source.md) | Get and set the symbol name in the data feed, to which the gateway connects.  
[Symbol](IMTConGatewayTranslate/Symbol.md) | Get and set the target symbol name in the trading platform.  
[BidMarkup](IMTConGatewayTranslate/BidMarkup.md) | Gets and sets a markup value for the Bid price received for a symbol from the data source to which the gateway connects.  
[AskMarkup](IMTConGatewayTranslate/AskMarkup.md) | Gets and sets a markup value for the Ask price received for a symbol from the data source to which the gateway connects.  
[Digits](IMTConGatewayTranslate/Digits.md) | Get the number of digits after the decimal point in the price of the symbol that receives quotes.  
  
> Detailed information about [symbol and price translation features](../../Gateway-API/Symbol-and-Price-Translation.md) is available in the Gateway API section.
