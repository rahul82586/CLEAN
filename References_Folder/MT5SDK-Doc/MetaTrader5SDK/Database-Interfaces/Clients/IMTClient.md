# IMTClient

The IMTClient class is designed to describe clients. The class contains the following methods:

Method | Purpose  
---|---  
[Release](IMTClient/Release.md) | Delete the current object.  
[Assign](IMTClient/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTClient/Clear.md) | Clear an object.  
[RecordID](IMTClient/RecordID.md) | Get and set the client ID.  
[ClientType](IMTClient/ClientType.md) | Get and set the client type.  
[ClientStatus](IMTClient/ClientStatus.md) | Get and set a client's status.  
[KYCStatus](IMTClient/KYCStatus.md) | Get and set the [KYC verification](../../Configuration-Interfaces/KYC.md) status for a client.  
[AssignedManager](IMTClient/AssignedManager.md) | Get and set the manager responsible for the client.  
[DateCreated](IMTClient/DateCreated.md) | Get and set the client creation date.  
[DateModified](IMTClient/DateModified.md) | Get and set the client's last modification date.  
[ComplianceApprovedBy](IMTClient/ComplianceApprovedBy.md) | Get and set the manager who checked the client data and approved registration.  
[ComplianceClientCategory](IMTClient/ComplianceClientCategory.md) | Get and set the client compliance category, i.e. client classification based on the regulatory rules.  
[ComplianceDateApproval](IMTClient/ComplianceDateApproval.md) | Get and set client approval date.  
[ComplianceDateTermination](IMTClient/ComplianceDateTermination.md) | Get and set the date of service termination for the client.  
[LeadCampaign](IMTClient/LeadCampaign.md) | Get and set a lead campaign — the name of the marketing campaign a client was attracted by.  
[LeadSource](IMTClient/LeadSource.md) | Get and set a lead source — a website the client has come from.  
[Introducer](IMTClient/Introducer.md) | Get and set the login (trading account) of the user who attracted this client.  
[PersonTitle](IMTClient/PersonTitle.md) | Get and set the client title, such as Mr. or Mrs.  
[PersonName](IMTClient/PersonName.md) | Get and set the client name.  
[PersonMiddleName](IMTClient/PersonMiddleName.md) | Get and set the client's middle name.  
[PersonLastName](IMTClient/PersonLastName.md) | Get and set the client's last name.  
[PersonBirthDate](IMTClient/PersonBirthDate.md) | Get and set the client's date of birth.  
[PersonCitizenship](IMTClient/PersonCitizenship.md) | Get and set the client's citizenship.  
[PersonGender](IMTClient/PersonGender.md) | Get and set the client's gender.  
[PersonTaxID](IMTClient/PersonTaxID.md) | Get and set the client's tax ID, for example TIN.  
[PersonDocumentType](IMTClient/PersonDocumentType.md) | Get and set the client's identification document type: passport, driver's license, etc.  
[PersonDocumentNumber](IMTClient/PersonDocumentNumber.md) | Get and set the number of the identification document (of passport, driver's license, etc.).  
[PersonDocumentDate](IMTClient/PersonDocumentDate.md) | Get and set the issue date of the identification document (of passport, driver's license, etc.).  
[PersonDocumentExpiration](IMTClient/PersonDocumentExpiration.md) | Get and set the expiration date of the identification document (of passport, driver's license, etc.).  
[PersonDocumentExtra](IMTClient/PersonDocumentExtra.md) | Get and set additional information (comment) to the identification document.  
[PersonEmployment](IMTClient/PersonEmployment.md) | Get and set the client's employment status.  
[PersonIndustry](IMTClient/PersonIndustry.md) | Get and set the client's employment industry.  
[PersonEducation](IMTClient/PersonEducation.md) | Get and set the client's education level.  
[PersonWealthSource](IMTClient/PersonWealthSource.md) | Get and set the client's income source.  
[PersonAnnualIncome](IMTClient/PersonAnnualIncome.md) | Get and set the client's annual income amount  
[PersonNetWorth](IMTClient/PersonNetWorth.md) | Get and set the amount of the client's net assets.  
[PersonAnnualDeposit](IMTClient/PersonAnnualDeposit.md) | Get and set the amount of the client's annual deposit.  
[CompanyName](IMTClient/CompanyName.md) | Get and set the company name (for corporate clients).  
[CompanyRegNumber](IMTClient/CompanyRegNumber.md) | Get and set the company registration number (for corporate clients).  
[CompanyRegDate](IMTClient/CompanyRegDate.md) | Get and set the company registration date (for corporate clients).  
[CompanyRegAuthority](IMTClient/CompanyRegAuthority.md) | Get and set the name of the registration authority with which the company was registered (for corporate body).  
[CompanyVat](IMTClient/CompanyVat.md) | Get and set the VAT payer ID (for corporate clients).  
[CompanyLei](IMTClient/CompanyLei.md) | Get and set the LEI number for EMIR reports (for corporate clients).  
[CompanyLicenseNumber](IMTClient/CompanyLicenseNumber.md) | Get and set the license number (for corporate clients).  
[CompanyLicenseAuthority](IMTClient/CompanyLicenseAuthority.md) | Get and set the name of the licensing authority (for corporate clients).  
[CompanyCountry](IMTClient/CompanyCountry.md) | Get and set the company's country of incorporation (for corporate clients).  
[CompanyAddress](IMTClient/CompanyAddress.md) | Get and set the company's legal address (for corporate clients).  
[CompanyWebsite](IMTClient/CompanyWebsite.md) | Get and set the website address (for corporate clients).  
[ContactPreferred](IMTClient/ContactPreferred.md) | Get and set the client's preferred contact methods.  
[ContactLanguage](IMTClient/ContactLanguage.md) | Get and set the language spoken by the client.  
[ContactEmail](IMTClient/ContactEmail.md) | Get and set the client's email address.  
[ContactPhone](IMTClient/ContactPhone.md) | Get and set the client's phone number.  
[ContactMessengers](IMTClient/ContactMessengers.md) | Get and set a list of client's IM accounts.  
[ContactSocialNetworks](IMTClient/ContactSocialNetworks.md) | Get and set a list of client's social media accounts.  
[ContactLastDate](IMTClient/ContactLastDate.md) | Get and set the date of the last client contact.  
[AddressCountry](IMTClient/AddressCountry.md) | Get and set the client's country of residence.  
[AddressPostcode](IMTClient/AddressPostcode.md) | Get and set the client's zip code.  
[AddressStreet](IMTClient/AddressStreet.md) | Get and set the client's address.  
[AddressState](IMTClient/AddressState.md) | Get and set the client's region of residence.  
[AddressCity](IMTClient/AddressCity.md) | Get and set the client's city of residence.  
[ExperienceFX](IMTClient/ExperienceFX.md) | Get and set information about the client's Forex trading experience.  
[ExperienceCFD](IMTClient/ExperienceCFD.md) | Get and set information about the client's CFD trading experience.  
[ExperienceFutures](IMTClient/ExperienceFutures.md) | Get and set information about the client's Futures trading experience.  
[ExperienceStocks](IMTClient/ExperienceStocks.md) | Get and set information about the client's Stock trading experience.  
[TradingGroup](IMTClient/TradingGroup.md) | Get and set the preferred trading group for the client.  
[ClientOrigin](IMTClient/ClientOrigin.md) | Get and set the client record creation method.  
[ClientOriginLogin](IMTClient/ClientOriginLogin.md) | Get and set the trading account number, based on which the client was created.  
[ClientExternalID](IMTClient/ClientExternalID.md) | Get and set the client ID in an external trading system.
