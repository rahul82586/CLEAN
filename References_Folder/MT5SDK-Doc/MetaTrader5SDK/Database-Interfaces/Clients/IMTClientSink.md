# IMTClientSink

The IMTClientSink class is designed for operations with the client database events. The class contains the following methods:

Method | Purpose  
---|---  
[OnClientAdd](IMTClientSink/OnClientAdd.md) | New client adding event handler.  
[OnClientUpdate](IMTClientSink/OnClientUpdate.md) | Client update event handler.  
[OnClientDelete](IMTClientSink/OnClientDelete.md) | Client deletion event handler.
