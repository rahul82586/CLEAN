# IMTCommentSink

The IMTCommentSink class is designed for working with the comments database events. The class contains the following methods:

Method | Purpose  
---|---  
[OnCommentAdd](IMTCommentSink/OnCommentAdd.md) | New comment adding event handler.  
[OnCommentUpdate](IMTCommentSink/OnCommentUpdate.md) | Comment update event handler.  
[OnCommentDelete](IMTCommentSink/OnCommentDelete.md) | Comment deletion event handler.
