# IMTDocumentSink

The IMTDocumentSink class is designed for operations with the document database events. The class contains the following methods:

Method | Purpose  
---|---  
[OnDocumentAdd](IMTDocumentSink/OnDocumentAdd.md) | New document adding event handler.  
[OnDocumentUpdate](IMTDocumentSink/OnDocumentUpdate.md) | Document update event handler.  
[OnDocumentDelete](IMTDocumentSink/OnDocumentDelete.md) | Document deletion event handler.
