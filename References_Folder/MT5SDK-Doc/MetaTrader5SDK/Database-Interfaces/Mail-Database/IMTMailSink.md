# IMTMailSink

The IMTMailSink class contains the following methods:

Method | Purpose  
---|---  
[OnMail](IMTMailSink/OnMail.md) | A handler of the event of email receiving.  
[HookMail](IMTMailSink/HookMail.md) | A hook of the event of email receiving. This method is used only in the MetaTrader 5 Server API.
