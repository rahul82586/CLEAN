# IMTSubscriptionHistorySink

The IMTSubscriptionHistorySink class contains event handlers related to changes in the subscription action database.

Method | Purpose  
---|---  
[OnSubscriptionHistoryAdd](IMTSubscriptionHistorySink/OnSubscriptionHistoryAdd.md) | Event handler for adding a subscription action to the database.  
[OnSubscriptionHistoryUpdate](IMTSubscriptionHistorySink/OnSubscriptionHistoryUpdate.md) | Subscription action change event handler.  
[OnSubscriptionHistoryDelete](IMTSubscriptionHistorySink/OnSubscriptionHistoryDelete.md) | Event handler for deleting a subscription action from the database.
