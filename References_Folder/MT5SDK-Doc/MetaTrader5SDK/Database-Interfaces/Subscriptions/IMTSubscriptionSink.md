# IMTSubscriptionSink

The IMTSubscriptionSink class contains event handlers related to changes in the subscriptions database.

Method | Purpose  
---|---  
[OnSubscriptionAdd](IMTSubscriptionSink/OnSubscriptionAdd.md) | Event handler for adding a subscription to the database.  
[OnSubscriptionUpdate](IMTSubscriptionSink/OnSubscriptionUpdate.md) | Subscription change event handler.  
[OnSubscriptionDelete](IMTSubscriptionSink/OnSubscriptionDelete.md) | Event handler for deleting a subscription from the database.  
[OnSubscriptionJoin](IMTSubscriptionSink/OnSubscriptionJoin.md) | Subscribing event handler.  
[OnSubscriptionCancel](IMTSubscriptionSink/OnSubscriptionCancel.md) | Unsubscribing event handler.
