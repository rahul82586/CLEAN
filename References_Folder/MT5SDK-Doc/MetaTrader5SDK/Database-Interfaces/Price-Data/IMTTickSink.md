# IMTTickSink

The IMTTickSink class contains the following methods:

Method | Purpose  
---|---  
[OnTick](IMTTickSink/OnTick.md) | A handler of the event of new quote arrival.  
[OnTickStat](IMTTickSink/OnTickStat.md) | A handler of the event of update of the statistical information about a price.  
[HookTick](IMTTickSink/HookTick.md) | A hook of an event of new quote arrival. This method is used only in the MetaTrader 5 Server API.  
[HookTickStat](IMTTickSink/HookTickStat.md) | A hook of an event of update of the statistical information about a price. This method is used only in the MetaTrader 5 Server API.
