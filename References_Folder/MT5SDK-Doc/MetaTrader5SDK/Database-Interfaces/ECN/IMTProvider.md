# IMTECNProvider

This interface provides access to the parameter of the [provider (#providers)](https://support.metaquotes.net/en/docs/mt5/platform/administration/ecn/ecn_matching#providers) via which the requests are executed.

Method | Purpose  
---|---  
[Release](IMTECNProvider/IMTProvider-Release.md) | Delete the current object.  
[Assign](IMTECNProvider/IMTProvider-Assign.md) | Assign a passed object to the current one.  
[Clear](IMTECNProvider/IMTProvider-Clear.md) | Clear an object.  
[ID](IMTECNProvider/IMTProvider-ID.md) | Get the record ID.  
[ProviderID](IMTECNProvider/IMTProvider-ProviderID.md) | Get the ID of the provider through which the order is forwarded to the external system.  
[Name](IMTECNProvider/IMTProvider-Name.md) | Get the name of the provider through which the order is forwarded to the external system.  
[Module](IMTECNProvider/IMTProvider-Module.md) | Get the name of the gateway through which the order is forwarded to the external system.  
[Version](IMTECNProvider/IMTProvider-Version.md) | Get the version of the gateway through which the order is forwarded to the external system.
