# Byte Stream

MetaTrader 5 API includes the special interface [IMTByteStream](Byte-Stream/IMTByteStream.md), which provides for an easier operation with unformatted byte data streams. These data can be passed using [user functions](../Manager-API/Manager-Interface/Custom-Functions.md).
