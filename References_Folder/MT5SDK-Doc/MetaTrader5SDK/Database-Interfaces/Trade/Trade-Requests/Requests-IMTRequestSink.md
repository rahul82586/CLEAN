# IMTRequestSink

The IMTRequestSink class contains the following methods:

Method | Purpose  
---|---  
[OnRequestAdd](IMTRequestSink/Requests-OnRequestAdd.md) | A handler of the event of adding a trade request.  
[OnRequestUpdate](IMTRequestSink/Requests-OnRequestUpdate.md) | A handler of the event of trade request change.  
[OnRequestDelete](IMTRequestSink/Requests-OnRequestDelete.md) | A handler of the event of a trade request deletion.  
[OnRequestSync](IMTRequestSink/Requests-OnRequestSync.md) | A handler of the event of synchronization of a queue of trade requests.
