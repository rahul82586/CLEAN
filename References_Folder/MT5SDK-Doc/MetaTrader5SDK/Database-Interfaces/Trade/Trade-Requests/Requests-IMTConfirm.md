## How to perform request confirmation (#fill-confirmation)

When responding to any type of request, the following fields should be filled in IMTConfirm:

  * [IMTConfirm::ID](IMTConfirm/Requests-ID.md) — the ID of the request, in response to which the confirmation will be formed ([IMTRequest::ID](IMTRequest/Requests-ID.md)).
  * [IMTConfirm::Retcode](IMTConfirm/Requests-Retcode.md) — response code for the request.
  * [IMTConfirm::Comment](IMTConfirm/Requests-Comment.md) — an optional field. If a comment is specified, it will be shown to the client in the trading dialog instead of the standard message corresponding to the response code.



The below table contains the IMTConfirm fields that should be filled depending on the type of request ([IMTRequest::Action](IMTRequest/Requests-Action.md)).
