# IMTSummaryArray

The IMTSummaryArray class contains the following methods:

Method | Purpose  
---|---  
[Release](IMTSummaryArray/Release.md) | Delete the current object.  
[Assign](IMTSummaryArray/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTSummaryArray/Clear.md) | Clear an object.  
[Add](IMTSummaryArray/Add.md) | Adds an object of the summary position record or an array of records at the end of the array.  
[AddCopy](IMTSummaryArray/AddCopy.md) | Adds a copy of an object of the summary position record or an array of records at the end of the array.  
[Delete](IMTSummaryArray/Delete.md) | Deletes the summary position record object from the array by its index.  
[Detach](IMTSummaryArray/Detach.md) | Detaches the summary position record object from the array.  
[Update](IMTSummaryArray/Update.md) | Modifies a summary position record in the array.  
[UpdateCopy](IMTSummaryArray/UpdateCopy.md) | Modifies a summary position record at the specified position of an array by copying the parameters of the passed object of a summary position.  
[Shift](IMTSummaryArray/Shift.md) | Modifies the position of a summary position record in the array.  
[Total](IMTSummaryArray/Total.md) | Gets the number of summary position record objects in an array.  
[Next](IMTSummaryArray/Next.md) | Gets the summary position record object by its index.  
[Sort](IMTSummaryArray/Sort.md) | Sort an array using the sort function passed.  
[Search](IMTSummaryArray/Search.md) | Search in an array the array element that matches the search key.  
[SearchGreatOrEq](IMTSummaryArray/SearchGreatOrEq.md) | Search in an array the first element greater than or equal to the search key.  
[SearchGreater](IMTSummaryArray/SearchGreater.md) | Search in an array the first element greater than the search key.  
[SearchLessOrEq](IMTSummaryArray/SearchLessOrEq.md) | Search in an array the first element less than or equal to the search key.  
[SearchLess](IMTSummaryArray/SearchLess.md) | Search in an array the first element less than the search key.  
[SearchLeft](IMTSummaryArray/SearchLeft.md) | Search in an array the first element equal to the search key.  
[SearchRight](IMTSummaryArray/SearchRight.md) | Search in an array the last element equal to the search key.
