# IMTExposure

The IMTExposure class contains the following methods:

Method | Purpose  
---|---  
[Release](IMTExposure/Release.md) | Delete the current object.  
[Assign](IMTExposure/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTExposure/Clear.md) | Clear an object.  
[Symbol](IMTExposure/Symbol.md) | Gets the name of an asset.  
[Digits](IMTExposure/Digits.md) | Gets the number of decimal places in the price of the asset.  
[VolumeClients](IMTExposure/VolumeClients.md) | Gets the volume of client positions on the asset.  
[VolumeCoverage](IMTExposure/VolumeCoverage.md) | Gets the volume of positions on a hedge account for the asset.  
[PriceRate](IMTExposure/PriceRate.md) | The rate of conversion of the net total to the selected currency.  
[VolumeNet](IMTExposure/VolumeNet.md) | The difference between the volume of client positions and hedged positions.
