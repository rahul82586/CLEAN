# IMTExposureArray

The IMTExposureArray class contains the following methods:

Method | Purpose  
---|---  
[Release](IMTExposureArray/Release.md) | Delete the current object.  
[Assign](IMTExposureArray/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTExposureArray/Clear.md) | Clear an object.  
[Add](IMTExposureArray/Add.md) | Adds an object of the asset record or an array of records at the end of the array.  
[AddCopy](IMTExposureArray/AddCopy.md) | Adds a copy of the object of the asset record or an array of records at the end of the array.  
[Delete](IMTExposureArray/Delete.md) | Deletes the asset record object from the array by its index.  
[Detach](IMTExposureArray/Detach.md) | Detaches the asset record object from an array.  
[Update](IMTExposureArray/Update.md) | Modifies the asset record at the specified position of an array.  
[UpdateCopy](IMTExposureArray/UpdateCopy.md) | Changes the asset record at the specified position of an array by copying the parameters of the passed asset object.  
[Shift](IMTExposureArray/Shift.md) | Changes the position of an asset record in the array.  
[Total](IMTExposureArray/Total.md) | Gets the number of asset record objects in the array.  
[Next](IMTExposureArray/Next.md) | Gets an asset record object by its index.  
[Sort](IMTExposureArray/Sort.md) | Sort an array using the sort function passed.  
[Search](IMTExposureArray/Search.md) | Search in an array the array element that matches the search key.  
[SearchGreatOrEq](IMTExposureArray/SearchGreatOrEq.md) | Search in an array the first element greater than or equal to the search key.  
[SearchGreater](IMTExposureArray/SearchGreater.md) | Search in an array the first element greater than the search key.  
[SearchLessOrEq](IMTExposureArray/SearchLessOrEq.md) | Search in an array the first element less than or equal to the search key.  
[SearchLess](IMTExposureArray/SearchLess.md) | Search in an array the first element less than the search key.  
[SearchLeft](IMTExposureArray/SearchLeft.md) | Search in an array the first element equal to the search key.  
[SearchRight](IMTExposureArray/SearchRight.md) | Search in an array the last element equal to the search key.
