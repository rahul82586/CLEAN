# Trade Requests

Interfaces provide access to managing trade requests received on the server, as well as allow creating requests.

The following interfaces are available for working with trade requests:

  * [IMTRequest](Trade-Requests/Requests-IMTRequest.md)  
An interface that provides access to the parameters of trade requests.
  * [IMTRequestArray](Trade-Requests/Requests-IMTRequestArray.md)  
An interface for working with the arrays of trade requests.
  * [IMTRequestSink](Trade-Requests/Requests-IMTRequestSink.md)  
An interface that contains handlers of events associated with trade requests.
  * [IMTConfirm](Trade-Requests/Requests-IMTConfirm.md)  
An interface for confirming trade requests.
  * [IMTExecution](Trade-Requests/Requests-IMTExecution.md)  
A trade execution interface.
