# IMTOrderSink

The IMTOrderSink class contains the following methods:

Method | Purpose  
---|---  
[OnOrderAdd](IMTOrderSink/OnOrderAdd.md) | A handler of the event of adding an open order.  
[OnOrderUpdate](IMTOrderSink/OnOrderUpdate.md) | A handler of the event of modifying an open order.  
[OnOrderDelete](IMTOrderSink/OnOrderDelete.md) | A handler of the event of deleting an open order.  
[OnOrderClean](IMTOrderSink/OnOrderClean.md) | A handler of the event of clearing open orders of a client.  
[OnOrderSync](IMTOrderSink/OnOrderSync.md) | A handler of the event of synchronization of a database of open orders.
