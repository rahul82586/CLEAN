# IMTHistorySink

The IMTHistorySink class contains the following methods:

Method | Purpose  
---|---  
[OnHistoryAdd](IMTHistorySink/OnHistoryAdd.md) | A handler of the event of adding a closed order.  
[OnHistoryUpdate](IMTHistorySink/OnHistoryUpdate.md) | A handler of the event of modifying a closed order.  
[OnHistoryDelete](IMTHistorySink/OnHistoryDelete.md) | A handler of the event of deleting a closed order.  
[OnHistoryClean](IMTHistorySink/OnHistoryClean.md) | A handler of the event of clearing closed orders of a client.  
[OnHistorySync](IMTHistorySink/OnHistorySync.md) | A handler of the event of synchronization of a database of closed orders.  
  
> IMTHistorySink is used in MetaTrader 5 Server API only.
