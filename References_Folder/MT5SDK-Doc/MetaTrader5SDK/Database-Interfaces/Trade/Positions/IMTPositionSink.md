# IMTPositionSink

The IMTPositionSink class contains the following methods:

Method | Purpose  
---|---  
[OnPositionAdd](IMTPositionSink/OnPositionAdd.md) | A handler of the event of adding a position.  
[OnPositionUpdate](IMTPositionSink/OnPositionUpdate.md) | A handler of an event of trade position modification.  
[OnPositionDelete](IMTPositionSink/OnPositionDelete.md) | A handler of an event of trade position deletion.  
[OnPositionClean](IMTPositionSink/OnPositionClean.md) | A handler of the event of clearing trade positions of a client.  
[OnPositionSync](IMTPositionSink/OnPositionSync.md) | A handler of the event of synchronization of a database of trade positions.
