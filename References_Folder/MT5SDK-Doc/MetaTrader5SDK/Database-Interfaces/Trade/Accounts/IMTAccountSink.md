# IMTAccountSink

The IMTAccountSink class is designed for working with the events related to changes in the account trading state. The class contains the following methods:

Method | Purpose  
---|---  
[OnAccountMarginCallEnter](IMTAccountSink/OnAccountMarginCallEnter.md) | The event handler for the account entering the Margin Call state. Used only in the Manager API.  
[OnAccountMarginCallLeave](IMTAccountSink/OnAccountMarginCallLeave.md) | The event handler for the account exiting the Margin Call state. Used only in the Manager API.  
[OnAccountStopOutEnter](IMTAccountSink/OnAccountStopOutEnter.md) | The event handler for the account entering the Stop Out state. Used only in the Manager API.  
[OnAccountStopOutLeave](IMTAccountSink/OnAccountStopOutLeave.md) | The event handler for the account exiting the Stop Out state. Used only in the Manager API.
