# IMTNewsSink

The IMTNewsSink class contains the following methods:

Method | Purpose  
---|---  
[OnNews](IMTNewsSink/OnNews.md) | A handler of the event of news receiving. This method is used only in the Server and Manager API.  
[HookNews](IMTNewsSink/HookNews.md) | A hook of the event of news receiving. This method is used only in the Server API.
