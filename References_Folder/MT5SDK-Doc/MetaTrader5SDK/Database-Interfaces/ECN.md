# The ECN

MetaTrader 5 API provides access to [built-in ECN](https://support.metaquotes.net/en/docs/mt5/platform/administration/ecn) databases. Functions from these section enable the detailed analysis of the current matching queue and history, of operations with liquidity providers and other data.

  * [IMTECNMatching](ECN/IMTMatching.md) — [matching order (#matching-orders-current)](https://support.metaquotes.net/en/docs/mt5/platform/administration/ecn/ecn_matching_history#matching-orders-current) object interface.
  * [IMTECNMatchingArray](ECN/IMTMatchingArray.md) — interface for the array of matching orders.
  * [IMTECNFilling](ECN/IMTFilling.md) — [filling order (#filling-orders-current)](https://support.metaquotes.net/en/docs/mt5/platform/administration/ecn/ecn_matching_history#filling-orders-current) object interface.
  * [IMTECNFillingArray](ECN/IMTFillingArray.md) — interface for the array of filling orders.
  * [IMTECNProvider](ECN/IMTProvider.md) — interface for the [provider (#providers)](https://support.metaquotes.net/en/docs/mt5/platform/administration/ecn/ecn_matching#providers) via which the requests are executed.
  * [IMTECNProviderArray](ECN/IMTProviderArray.md) — interface for an array of providers.
  * [IMTECNHistoryMatching](ECN/IMTHistoryMatching.md) — interface for the [matching order (#matching-orders)](https://support.metaquotes.net/en/docs/mt5/platform/administration/ecn/ecn_matching_history#matching-orders) object from history.
  * [IMTECNHistoryMatchingArray](ECN/IMTHistoryMatchingArray.md) — interface for an array of objects of matching orders from history.
  * [IMTECNHistoryFilling](ECN/IMTHistoryFilling.md) — interface for the [filling order (#filling-orders)](https://support.metaquotes.net/en/docs/mt5/platform/administration/ecn/ecn_matching_history#filling-orders) object from history.
  * [IMTECNHistoryFillingArray](ECN/IMTHistoryFillingArray.md) — interface for an array of objects of filling orders from history.
  * [IMTECNHistoryDeal](ECN/IMTHistoryDeal.md) — interface for the object of a [deal (#deals)](https://support.metaquotes.net/en/docs/mt5/platform/administration/ecn/ecn_matching_history#deals) from the ECN history.
  * [IMTECNHistoryDealArray](ECN/IMTHistoryDealArray.md) — interface for an array of objects of deals from the ECN history.
