# IMTOnline

The IMTOnline class contains the following methods:

Method | Purpose  
---|---  
[Release](IMTOnline/Release.md) | Delete the current object.  
[Assign](IMTOnline/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTOnline/Clear.md) | Clear an object.  
[SessionID](IMTOnline/SessionID.md) | Get a unique ID of a user connection session.  
[Login](IMTOnline/Login.md) | Get the login of a user.  
[Group](IMTOnline/Group.md) | Get the group to which the user is included.  
[Address](IMTOnline/Address.md) | Get the IP address from which the user connected to the server.  
[Type](IMTOnline/Type.md) | Get a user connection type.  
[Build](IMTOnline/Build.md) | Get build number of a terminal used for connection.  
[Time](IMTOnline/Time.md) | Gets connection date.  
[ComputerID](IMTOnline/ComputerID.md) | Get CID, i.e. the unique ID of the computer from which the user connected to the server.
