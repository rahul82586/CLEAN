# Email

The following requests are provided for operations with mail server settings in the trading platform:

Request | Description  
---|---  
[/api/email/add](Email/Add.md) | Add and update mail server configurations in the trading platform.  
[/api/email/delete](Email/Delete.md) | Delete mail server configurations from the trading platform.  
[/api/email/shift](Email/Shift.md) | Change the position of a mail server configuration in the list.  
[/api/email/total](Email/Get-Total.md) | Get the total number of mail server configurations available in the platform.  
[/api/email/next](Email/Get-by-Index.md) | Get the configuration of one or more mail servers by index in the list.  
[/api/email/get](Email/Get-by-Name.md) | Get a mail server configuration by name.  
[/api/email/send](Email/Send.md) | Send an email to a selected address.
