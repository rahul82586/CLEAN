# Common Configuration

The Web API provides the following requests for getting common settings of a trading platform:

Request | Description  
---|---  
[/api/common/get](Common/Get.md) | Get the common platform configuration.  
[/api/common/set](Common/Set.md) | Update the common platform configuration.  
  
The format, in which the data about the common configuration is passed, are described in the ["Data structure"](Common/Data-Structure.md) section.
