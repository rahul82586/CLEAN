# Gateways

The following requests are provided for operations with gateway settings in the trading platform:

Request | Description  
---|---  
[/api/gateway/restart](Gateways/Restart.md) | Restart all gateways in the platform.  
[/api/gateway/add](Gateways/Add.md) | Add or update a gateway configuration in the trading platform.  
[/api/gateway/delete](Gateways/Delete.md) | Delete a gateway configuration from the trading platform.  
[/api/gateway/shift](Gateways/Shift.md) | Change the position of a gateway configuration in the list.  
[/api/gateway/total](Gateways/Get-Total.md) | Get the total number of gateway configurations available in the platform.  
[/api/gateway/next](Gateways/Get-by-Index.md) | Get the configuration of one or more gateways by index in the list.  
[/api/gateway/get](Gateways/Get-by-Name.md) | Get a gateway configuration by the name.  
[/api/gateway/module/total](Gateways/Get-Total-Modules.md) | Get the number of gateway modules available in the platform.  
[/api/gateway/module/next](Gateways/Get-Module-by-Index.md) | Get a gateway module description by the index in the list.  
[/api/gateway/module/get](Gateways/Get-Module-by-Name.md) | Get the description of a gateway module by its name.  
[/api/gateway/get_position](Gateways/Get-Positions.md) | Get the current state of positions on trading accounts which are used by the gateway in an external system.
