# Firewall

The following requests are provided for receiving platform firewall settings:

Request | Description  
---|---  
[/api/holiday/add](Holidays/Add.md) | Add and update a holiday configuration in the trading platform.  
[/api/holiday/delete](Holidays/Delete.md) | Delete a holiday configuration from the trading platform.  
[/api/holiday/shift](Holidays/Shift.md) | Change the position of a holiday configuration in the list.  
[/api/holiday/total](Holidays/Get-Total.md) | Get the total number of holiday configurations existing in the platform.  
[/api/holiday/next](Holidays/Get-by-Index.md) | Get a holiday configuration description by the index in the list.
