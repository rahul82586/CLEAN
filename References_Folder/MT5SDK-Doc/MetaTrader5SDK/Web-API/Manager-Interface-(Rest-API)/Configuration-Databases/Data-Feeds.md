# Data Feeds

The following requests are provided for working with data feed settings in the trading platform:

Request | Description  
---|---  
[/api/feeder/restart](Data-Feeds/Restart.md) | Restart all data feeds in the platform.+  
[/api/feeder/add](Data-Feeds/Add.md) | Add and update a data feed configuration in the trading platform.  
[/api/feeder/delete](Data-Feeds/Delete.md) | Delete a data feed configuration from the trading platform.  
[/api/feeder/shift](Data-Feeds/Shift.md) | Change the position of a data feed configuration in the list.  
[/api/feeder/total](Data-Feeds/Get-Total.md) | Get the total number of data feed configurations existing in the platform.  
[/api/feeder/next](Data-Feeds/Get-by-Index.md) | Get the configuration of one or more data feeds by index in the list.  
[/api/feeder/get](Data-Feeds/Get-by-Name.md) | Get a data feed configuration by its name.  
[/api/feeder/module/total](Data-Feeds/Get-Total-Modules.md) | Get the number of data feed modules available in the platform.  
[/api/feeder/module/next](Data-Feeds/Get-Module-by-Index.md) | Get the description of a data feed module by the index in the list.  
[/api/feeder/module/get](Data-Feeds/Get-Module-by-Name.md) | Get the description of a data feed module by its name.
