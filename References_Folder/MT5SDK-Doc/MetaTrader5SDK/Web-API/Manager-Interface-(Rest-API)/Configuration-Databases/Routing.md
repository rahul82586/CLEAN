# Trade Request Routing

The following requests are provided for operations with routing settings in the trading platform:

Request | Description  
---|---  
[/api/route/add](Routing/Add.md) | Add and update a routing rule in the trading platform.  
[/api/route/delete](Routing/Delete.md) | Delete routing rules from the trading platform.  
[/api/route/shift](Routing/Shift.md) | Changes the position of a routing rule in the list.  
[/api/route/total](Routing/Get-Total.md) | Get the total number of routing rules existing in the platform.  
[/api/route/next](Routing/Get-by-Index.md) | Get one or more routing rules by index in the list.  
[/api/route/get](Routing/Get-by-Name.md) | Get a routing rule by its name.
