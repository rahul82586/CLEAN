# Firewall

The following requests are provided for receiving platform firewall settings:

Request | Description  
---|---  
[/api/firewall/add](Firewall/Add.md) | Add and update a trading platform firewall rule.  
[/api/firewall/delete](Firewall/Delete.md) | Delete a trading platform firewall rule.  
[/api/firewall/shift](Firewall/Shift.md) | Change the position of a firewall rule in the list.  
[/api/firewall/total](Firewall/Get-Total.md) | Get the total number of firewall rules existing in the platform.  
[/api/firewall/next](Firewall/Get-by-Index.md) | Get one or more firewall rules by index in the list.
