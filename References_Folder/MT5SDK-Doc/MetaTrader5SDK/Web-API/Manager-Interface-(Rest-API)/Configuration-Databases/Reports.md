# Reports

The following requests are provided for operations with report settings in the trading platform:

Request | Description  
---|---  
[/api/report/add](Reports/Add.md) | Add and update a report configuration in the trading platform.  
[/api/report/delete](Reports/Delete.md) | Delete a report configuration from the trading platform.  
[/api/report/shift](Reports/Shift.md) | Change the position of a report configuration in the list.  
[/api/report/total](Reports/Get-Total.md) | Get the total number of report configurations existing in the platform.  
[/api/report/next](Reports/Get-by-Index.md) | Get the configuration of one or more reports by index in the list.  
[/api/report/get](Reports/Get-by-Name.md) | Get a report configuration by its name.  
[/api/report/module/total](Reports/Get-Total-Modules.md) | Get the number of report modules available in the platform.  
[/api/report/module/next](Reports/Get-Module-by-Index.md) | Get the description of a report module by the index in the list.  
[/api/report/module/get](Reports/Get-Module-by-Name.md) | Get the description of a report module by its name.
