# Timing

The following requests are provided for operations with working hours settings in the trading platform:

Request | Description  
---|---  
[/api/time/server](Time/Get-Server.md) | Get the current server time.  
[/api/time/get](Time/Get-Settings.md) | Get the working time settings of the server.  
[/api/time/set](Time/Update-Settings.md) | Update the working time settings of the server.  
  
The format, in which the data about time configuration is passed, is described under the ["Data Structure"](Time/Data-Structure.md) section.
