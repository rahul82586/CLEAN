# Plugins

The following requests are provided for operations with plugin settings in the trading platform:

Request | Description  
---|---  
[/api/plugin/add](Plugins/Add.md) | Add and update a plugin configuration in the trading platform.  
[/api/plugin/delete](Plugins/Delete.md) | Delete a plugin configuration from the trading platform.  
[/api/plugin/shift](Plugins/Shift.md) | Change the position of a plugun configuration in the list.  
[/api/plugin/total](Plugins/Get-Total.md) | Get the total number of plugin configurations existing in the platform.  
[/api/plugin/next](Plugins/Get-by-Index.md) | Get the configuration of one or more plugins by index in the list.  
[/api/plugin/get](Plugins/Get-by-Name.md) | Get plugin configuration by its name.  
[/api/plugin/module/total](Plugins/Get-Total-Modules.md) | Get the number of plugin modules available in the platform.  
[/api/plugin/module/next](Plugins/Get-Module-by-Index.md) | Get the description of a plugin module by the index in the list.  
[/api/plugin/module/get](Plugins/Get-Module-by-Name.md) | Get the description of a plugin module by its name.
