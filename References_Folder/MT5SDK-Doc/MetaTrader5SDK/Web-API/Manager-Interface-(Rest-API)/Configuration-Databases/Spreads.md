# Spreads

The following requests are provided for receiving platform spread settings:

Request | Description  
---|---  
[/api/spread/add](Spreads/Add.md) | Add and update spread configurations in the trading platform.  
[/api/spread/delete](Spreads/Delete.md) | Delete spread configurations from the trading platform.  
[/api/spread/shift](Spreads/Shift.md) | Change the position of a spread configuration in the list.  
[/api/spread/total](Spreads/Get-Total.md) | Get the total number of spread configurations existing in the platform.  
[/api/spread/next](Spreads/Get-by-Index.md) | Get one or more spread configurations by index in the list.
