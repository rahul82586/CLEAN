# History Synchronization

The following requests are provided for working with historical data synchronization settings in the trading platform:

Request | Description  
---|---  
[/api/history_sync/start](History-Synchronization/Start.md) | Start history synchronization in accordance with configuration settings.  
[/api/history_sync/add](History-Synchronization/Add.md) | Add and update a history synchronization configuration in the trading platform.  
[/api/history_sync/delete](History-Synchronization/Delete.md) | Delete a history synchronization configuration from the trading platform.  
[/api/history_sync/shift](History-Synchronization/Shift.md) | Change the position of a synchronization configuration in the list.  
[/api/history_sync/total](History-Synchronization/Get-Total.md) | Get the total number of history synchronization configurations existing in the platform.  
[/api/history_sync/next](History-Synchronization/Get-by-Index.md) | Get one or more history synchronization configurations by index in the list.
