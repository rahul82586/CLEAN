# Managers

The following requests are provided for for operations with manager settings:

Request | Description  
---|---  
[/api/manager/add](Managers/Add.md) | Add and update a manager configuration in the trading platform.  
[/api/manager/delete](Managers/Delete.md) | Delete manager configurations from the trading platform.  
[/api/manager/shift](Managers/Shift.md) | Change the position of a manager configuration in the list.  
[/api/manager/total](Managers/Get-Total.md) | Get the total number of manager configurations existing in the platform.  
[/api/manager/next](Managers/Get-by-Index.md) | Get one or more manager configurations by index in the list.  
[/api/manager/get](Managers/Get-by-Login.md) | Get a manager configuration by login.
