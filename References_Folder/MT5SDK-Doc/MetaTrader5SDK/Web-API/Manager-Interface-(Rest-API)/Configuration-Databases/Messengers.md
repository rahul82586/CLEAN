# Messengers

The following requests are provided for operations with messengers settings in the trading platform:

Request | Description  
---|---  
[/api/messenger/add](Messengers/Add.md) | Add and update messenger configurations in the trading platform.  
[/api/messenger/delete](Messengers/Delete.md) | Delete messenger configurations from the trading platform.  
[/api/messenger/shift](Messengers/Shift.md) | Change the position of a messenger configuration in the list.  
[/api/messenger/total](Messengers/Get-Total.md) | Get the total number of messenger configurations available in the platform.  
[/api/messenger/next](Messengers/Get-by-Index.md) | Get a messenger configuration by the index in the list.  
[/api/messenger/get](Messengers/Get-by-Name.md) | Get a messenger configuration by name.  
[/api/messenger/send](Messengers/Send-Message.md) | Send an SMS message.
