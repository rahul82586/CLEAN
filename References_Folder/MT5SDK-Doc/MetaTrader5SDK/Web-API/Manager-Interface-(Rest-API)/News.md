# News

The MetaTrader 5 Web API allows receiving and sending news to terminals via the platform's internal news system. The following requests are provided:

Request | Description  
---|---  
[/api/news/send](News/Send.md) | Send news.  
[/api/news/get](News/Get-Without-Body.md) | Get a brief news description without a body.  
[/api/news/get_body](News/Get-With-Body.md) | Get the full news description with its body.
