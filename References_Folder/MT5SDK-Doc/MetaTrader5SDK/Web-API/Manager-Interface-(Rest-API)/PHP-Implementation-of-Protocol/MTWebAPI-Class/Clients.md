# Clients

The methods described in this section allow working with the client base on the server:

Method | Purpose  
---|---  
[UserCreate](Clients/UserCreate.md) | Create an object of a client record.  
[UserAdd](Clients/UserAdd.md) | Create a client account on the server.  
[UserUpdate](Clients/UserUpdate.md) | Change a client account on the server.  
[UserDelete](Clients/UserDelete.md) | Delete a client account on the server.  
[UserGet](Clients/UserGet.md) | Get information about a client by the login.  
[UserPasswordCheck](Clients/UserPasswordCheck.md) | Check a client's password.  
[UserPasswordChange](Clients/UserPasswordChange.md) | Change a client's password.  
[UserAccountGet](Clients/UserAccountGet.md) | Get information about a client's trading account.  
[UserLogins](Clients/UserLogins.md) | Returns an array of logins of the clients who are included in the specified group.
