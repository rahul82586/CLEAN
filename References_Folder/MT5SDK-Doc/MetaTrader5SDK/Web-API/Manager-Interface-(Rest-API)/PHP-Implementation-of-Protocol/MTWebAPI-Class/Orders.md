# Orders

Use the methods described in this section to get clients' orders. The following methods are available:

Method | Purpose  
---|---  
[OrderGet](Orders/OrderGet.md) | Get a trade order by a ticket.  
[OrderGetTotal](Orders/OrderGetTotal.md) | Get the number of open orders of a client by the login.  
[OrderGetPage](Orders/OrderGetPage.md) | Get open orders of a client by the login.  
[HistoryGet](Orders/HistoryGet.md) | Get a closed order by the ticket.  
[HistoryGetTotal](Orders/HistoryGetTotal.md) | Get the number of closed orders of a client by the login in the specified time range.  
[HistoryGetPage](Orders/HistoryGetPage.md) | Get closed orders of a client by the login.
