# Timing

There are two commands for receiving the working time settings of the trading platform:

Method | Purpose  
---|---  
[TimeGet](Timing/TimeGet.md) | Get the working time settings of the server.  
[TimeServer](Timing/TimeServer.md) | Get the current server time.
