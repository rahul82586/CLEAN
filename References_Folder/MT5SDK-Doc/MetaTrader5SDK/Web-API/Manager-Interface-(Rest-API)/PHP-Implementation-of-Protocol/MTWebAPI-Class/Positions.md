# Positions

Use the methods described in this section to get clients' positions. The following methods are available:

Method | Purpose  
---|---  
[PositionGet](Positions/PositionGet.md) | Get a client's trade position by the symbol.  
[PositionGetTotal](Positions/PositionGetTotal.md) | Get the number of open positions of a client by the login.  
[PositionGetPage](Positions/PositionGetPage.md) | Get open positions of a client by the login.
