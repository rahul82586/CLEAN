# Groups

Use the methods described in this section to obtain the parameters of client groups on the server:

Method | Purpose  
---|---  
[GroupCreate](Groups/GroupCreate.md) | Create an object of a client group.  
[GroupAdd](Groups/GroupAdd.md) | Add or change a group configuration on the server.  
[GroupDelete](Groups/GroupDelete.md) | Delete a group configuration with the specified name.  
[GroupTotal](Groups/GroupTotal.md) | Get the number of groups created on the trade server.  
[GroupNext](Groups/GroupNext.md) | Get the group configuration by its index in the list of groups of the platform.  
[GroupGet](Groups/GroupGet.md) | Get the group configuration by its name.
