# Manage Logging

Implementation of the Web API protocol in PHP includes the option of logging activities of a web client. This section describes the methods for managing logging:

Method | Purpose  
---|---  
[SetLoggerIsWrite](Logging-Management/SetLoggerIsWrite.md) | Enable/disable logging of the Web API.  
[SetLoggerFilePath](Logging-Management/SetLoggerFilePath.md) | Set the path to the folder where you want to place the log files.  
[SetLoggerFilePrefix](Logging-Management/SetLoggerFilePrefix.md) | Set a prefix for naming log files.  
[SetLoggerWriteDebug](Logging-Management/SetLoggerWriteDebug.md) | Enable/disable logging of debug messages of the Web API.
