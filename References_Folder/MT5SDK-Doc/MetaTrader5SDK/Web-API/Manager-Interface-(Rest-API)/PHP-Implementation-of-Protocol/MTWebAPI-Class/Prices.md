# Prices

Use the methods described in this section to get price data from a trade server. The following methods are available:

Method | Purpose  
---|---  
[TickLast](Prices/TickLast.md) | Get the current prices of symbols.  
[TickLastGroup](Prices/TickLastGroup.md) | Get the current prices of symbols taking into account conversion for the specified group.  
[TickStat](Prices/TickStat.md) | Get statistical data of symbols.
