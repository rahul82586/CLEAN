# Symbols

Use the methods described in this section to obtain settings of symbols on a trade server:

Method | Purpose  
---|---  
[SymbolAdd](Symbols/SymbolAdd.md) | Add or change a symbol configuration on the server.  
[SymbolDelete](Symbols/SymbolDelete.md) | Delete a symbol configuration with the specified name.  
[SymbolTotal](Symbols/SymbolTotal.md) | Get the number of symbols created on the trade server.  
[SymbolNext](Symbols/SymbolNext.md) | Get the configuration of a symbol by its index in the list of symbols of the platform.  
[SymbolGet](Symbols/SymbolGet.md) | Gets the symbol configuration by the name.  
[SymbolGetGroup](Symbols/SymbolGetGroup.md) | Get an individual configuration of a symbol for a group by the name of the symbol.
