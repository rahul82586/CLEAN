# Deals

Use the methods described in this section to get clients' deals. The following methods are available:

Methods | Purpose  
---|---  
[DealGet](Deals/DealGet.md) | Get a deal by a ticket.  
[DealGetTotal](Deals/DealGetTotal.md) | Get the number of a client's deals by the login.  
[DealGetPage](Deals/DealGetPage.md) | Get the deals of a client by the login in the specified time range.
