# Connect/Disconnect

The methods described in this section allow you to connect and disconnect a Web client from the trade server.

Method | Purpose  
---|---  
[Connect](Connect-Disconnect/Connect.md) | Connect a Web client to a trade server.  
[Disconnect](Connect-Disconnect/Disconnect.md) | Disconnect a Web client from a trade server.  
[IsConnected](Connect-Disconnect/IsConnected.md) | Check the connection status of the Web client to the trade server.  
[Ping](Connect-Disconnect/Ping.md) | Send empty packets to the server to maintain connection.
