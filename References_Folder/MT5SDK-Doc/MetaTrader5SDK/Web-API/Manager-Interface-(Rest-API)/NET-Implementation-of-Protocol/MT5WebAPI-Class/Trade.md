# Trade

The methods described in this section allow conducting trade operations on client accounts. Currently, one method is implemented:

Method | Purpose  
---|---  
[UserDepositChange](Trade/UserDepositChange.md) | Conducts balance operations on a client's account.  
[TradeBalance](Trade/Balance.md) | Conduct balance operations on an account with getting the balance deal ticket.
