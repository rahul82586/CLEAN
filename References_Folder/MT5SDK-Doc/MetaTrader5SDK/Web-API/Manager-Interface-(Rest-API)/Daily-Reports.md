# Daily Reports

The following requests are provided for operations with daily reports in the trading platform:

Request | Description  
---|---  
[/api/daily_get](Daily-Reports/Get.md) | Get daily reports by the date range and login.  
[/api/daily_get_light](Daily-Reports/Get-Light.md) | Get lightweight versions of daily reports by the date range and login.
