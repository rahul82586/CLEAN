# Trade

The MetaTrader 5 Web API allows to perform trade operations on client accounts. Currently one request is available:

Request | Description  
---|---  
[/api/trade/balance](Trade-Requests/DepositWithdrawal.md) | Conduct balance operations on client accounts.  
[/api/trade/calc_rate_buy](Trade-Requests/Calculate-Conversion-Rate-for-Buy.md) | Calculate the rate for buying one currency for another currency in accordance with the account group settings.  
[/api/trade/calc_rate_sell](Trade-Requests/Calculate-Conversion-Rate-for-Sell.md) | Calculate the rate for selling one currency for another currency in accordance with the account group settings.  
[/api/trade/check_margin](Trade-Requests/Check-Margin.md) | Check the availability of margin required for order execution.  
[/api/trade/calc_profit](Trade-Requests/Calculate-Profit.md) | Calculate profit of a position closed under specified trading conditions.  
[/api/dealer/send_request](Trade-Requests/Send-Request.md) | Send a trade request to a server on behalf of the dealer.  
[/api/dealer/get_request_result](Trade-Requests/Get-Request-Result.md) | Get the result of a trade request execution on the server.
