# Mail

The MetaTrader 5 Web API allows receiving and sending emails via the platform's internal mail system. The following requests are provided:

Request | Description  
---|---  
[/api/mail/send](Mail/Send.md) | Send mail.  
[/api/mail/get](Mail/Get-Without-Body.md) | Get a brief email description without a body and attachments.  
[/api/mail/get_body](Mail/Get-With-Body.md) | Get the full email description with its body and attachments.
