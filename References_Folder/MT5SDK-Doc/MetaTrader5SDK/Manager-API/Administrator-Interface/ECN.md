# ECN

MetaTrader 5 API provides access to [built-in ECN](https://support.metaquotes.net/en/docs/mt5/platform/administration/ecn) databases. Functions from these section enable the detailed analysis of the current matching queue and history, of operations with liquidity providers and other data.

Function | Purpose  
---|---  
[ECNCreateMatching](ECN/CreateMatching.md) | Create a matching order object.  
[ECNCreateMatchingArray](ECN/CreateMatchingArray.md) | Create an array of matching order objects.  
[ECNCreateFilling](ECN/CreateFilling.md) | Create a filling order object.  
[ECNCreateFillingArray](ECN/CreateFillingArray.md) | Create an array of filling objects.  
[ECNCreateProvider](ECN/CreateProvider.md) | Create an object of a provider via which orders are executed.  
[ECNCreateProviderArray](ECN/CreateProviderArray.md) | Create an object of the array of providers via which orders are executed.  
[ECNCreateHistoryMatching](ECN/CreateHistoryMatching.md) | Create an object of a matching order from history.  
[ECNCreateHistoryMatchingArray](ECN/CreateHistoryMatchingArray.md) | Create an array of matching order objects from history.  
[ECNCreateHistoryFilling](ECN/CreateHistoryFilling.md) | Create an object of a filling order from history.  
[ECNCreateHistoryFillingArray](ECN/CreateHistoryFillingArray.md) | Create an array of filling order objects from history.  
[ECNCreateHistoryDeal](ECN/CreateHistoryDeal.md) | Create an object of a deal from the ECN history.  
[ECNCreateHistoryDealArray](ECN/CreateHistoryDealArray.md) | Create an object of an array of deals from the ECN history.  
[ECNRequestByGroup](ECN/RequestByGroup.md) | Request the current state of matching for the specified client groups.  
[ECNRequestByLogins](ECN/RequestByLogins.md) | Request the current state of matching for the specified logins.  
[ECNRequestByTickets](ECN/RequestByTickets.md) | Request the current state of matching for the specified order tickets.  
[ECNRequestHistoryByGroup](ECN/RequestHistoryByGroup.md) | Request the matching history for the specified client groups.  
[ECNRequestHistoryByLogins](ECN/RequestHistoryByLogins.md) | Request the matching history for the specified logins.  
[ECNRequestHistoryByTickets](ECN/RequestHistoryByTickets.md) | Request the matching history for the specified order tickets.
