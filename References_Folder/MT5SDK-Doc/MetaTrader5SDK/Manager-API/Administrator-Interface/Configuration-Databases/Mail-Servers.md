# Integration with mail services

The MetaTrader 5 platform features the built-in email service. The service is used to send trading reports to traders, as well as for the confirmation of email addresses specified during account opening via client terminals. For more details, please read the [MetaTrader 5 Administrator Help](https://support.metaquotes.net/en/docs/mt5/platform/administration/integration).

The functions described in this section enable users to manage mail server configurations, as well as to subscribe and to unsubscribe from events related to configuration changes.

Function | Purpose  
---|---  
[EmailCreate](Mail-Servers/EmailCreate.md) | Create a mail server configuration object.  
[EmailSubscribe](Mail-Servers/EmailSubscribe.md) | Subscribe to events and hooks related to mail server configurations.  
[EmailUnsubscribe](Mail-Servers/EmailUnsubscribe.md) | Unsubscribe from events and hooks related to mail server configurations.  
[EmailUpdate](Mail-Servers/EmailUpdate.md) | Add or update a mail server configuration.  
[EmailUpdateBatch](Mail-Servers/EmailUpdateBatch.md) | Add or edit multiple mail server configurations.  
[EmailDelete](Mail-Servers/EmailDelete.md) | Delete a mail server configuration by the name or index.  
[EmailDeleteBatch](Mail-Servers/EmailDeleteBatch.md) | Delete multiple mail server configurations.  
[EmailShift](Mail-Servers/EmailShift.md) | Change the position of a mail server configuration in the list.  
[EmailTotal](Mail-Servers/EmailTotal.md) | Get the total number of mail server configurations available in the platform.  
[EmailNext](Mail-Servers/EmailNext.md) | Get a mail server configuration by index.  
[EmailGet](Mail-Servers/EmailGet.md) | Get a mail server configuration by name.  
[EmailSend](Mail-Servers/EmailSend.md) | Send an email to a selected address.
