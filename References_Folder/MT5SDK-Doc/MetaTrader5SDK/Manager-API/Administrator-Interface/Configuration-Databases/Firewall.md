# Firewall Configuration

Functions allow managing the firewall configuration, as well subscribe and unsubscribe from events associated with its change.

To configure a firewall provides the configuring the firewall:

Function | Purpose  
---|---  
[FirewallCreate](Firewall/Create.md) | Create an object of the firewall configuration.  
[FirewallSubscribe](Firewall/Subscribe.md) | Subscribe to events associated with the firewall configuration.  
[FirewallUnsubscribe](Firewall/Unsubscribe.md) | Unsubscribe from events associated with the firewall configuration.  
[FirewallUpdate](Firewall/Update.md) | Add or update a firewall configuration.  
[FirewallUpdateBatch](Firewall/UpdateBatch.md) | Add or edit multiple firewall configurations.  
[FirewallDelete](Firewall/Delete.md) | Delete a configuration of a data feed by its index.  
[FirewallDeleteBatch](Firewall/DeleteBatch.md) | Delete multiple firewall configurations.  
[FirewallShift](Firewall/Shift.md) | Change the position of a firewall configuration in the list.  
[FirewallTotal](Firewall/Total.md) | The total number of firewall configurations available in the platform.  
[FirewallNex](Firewall/Next.md) | Get the firewall configuration by the index.
