# Configuration of Spreads

Functions allow managing spreads, as well subscribe and unsubscribe from events associated with their change.

The following functions for managing spreads are available:

Function | Purpose  
---|---  
[SpreadCreate](../../Manager-Interface/Configuration-Databases/Spreads/SpreadCreate.md) | Create an object of the configuration of a spread.  
[SpreadLegCreate](../../Manager-Interface/Configuration-Databases/Spreads/SpreadLegCreate.md) | Create an object of the configuration of a spread leg.  
[SpreadSubscribe](../../Manager-Interface/Configuration-Databases/Spreads/SpreadSubscribe.md) | Subscribe to events and hooks associated with the configuration of spreads.  
[SpreadUnsubscribe](../../Manager-Interface/Configuration-Databases/Spreads/SpreadUnsubscribe.md) | Unsubscribe from events and hooks associated with spread configuration.  
[SpreadUpdate](Spreads/SpreadUpdate.md) | Add or update a spread configuration.  
[SpreadUpdateBatch](Spreads/SpreadUpdateBatch.md) | Add or edit multiple spread configurations.  
[SpreadDelete](Spreads/SpreadDelete.md) | Deleting a spread configuration by the index.  
[SpreadDeleteBatch](Spreads/SpreadDeleteBatch.md) | Delete multiple spread configurations.  
[SpreadShift](Spreads/SpreadShift.md) | Change the position of a spread configuration in the list.  
[SpreadTotal](../../Manager-Interface/Configuration-Databases/Spreads/SpreadTotal.md) | The total number of spread configurations available in the platform.  
[SpreadNext](../../Manager-Interface/Configuration-Databases/Spreads/SpreadNext.md) | Receiving a spread configuration by the index.
