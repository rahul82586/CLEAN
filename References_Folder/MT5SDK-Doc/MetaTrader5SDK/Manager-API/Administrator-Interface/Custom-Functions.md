# Custom Functions

MetaTrader 5 Manager API provides the possibility of extending the protocol for running custom commands on the server. Currently, there are two functions for this purpose:

Function | Purpose  
---|---  
[CustomCommand](../Manager-Interface/Custom-Functions/CustomCommand.md) | Sends a custom command to the server.  
[CustomCreateStream](../Manager-Interface/Custom-Functions/CustomCreateStream.md) | Creation of an object of a byte stream.
