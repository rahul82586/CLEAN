# Positions

Using the functions, you can request a database of trade positions of the server and create new orders. The following functions are available for this purpose:

Function | Purpose  
---|---  
[PositionCreate](Positions/PositionCreate.md) | Create an object of a trade position.  
[PositionCreateArray](Positions/PositionCreateArray.md) | Create an object of the array of trade positions.  
[PositionRequest](Positions/PositionRequest.md) | Request from the server open positions by login.  
[PositionRequestByGroup](Positions/PositionRequestByGroup.md) | Request from the server open positions related to a client group.  
[PositionRequestByGroupSymbol](Positions/PositionRequestByGroupSymbol.md) | Request open positions from the server by group and symbol.  
[PositionRequestByLogins](Positions/PositionRequestByLogins.md) | Request from the server open positions by the list of logins.  
[PositionRequestByLoginsSymbol](Positions/PositionRequestByLoginsSymbol.md) | Request open positions from the server by list of logins and symbol.  
[PositionRequestByTickets](Positions/PositionRequestByTickets.md) | Request from the server open positions by the list of tickets.  
[PositionUpdate](Positions/PositionUpdate.md) | Update a position.  
[PositionUpdateBatch](Positions/PositionUpdateBatch.md) | Update positions in a server database in bulk.  
[PositionUpdateBatchArray](Positions/PositionUpdateBatchArray.md) | Update positions in a server database in bulk.  
[PositionDelete](Positions/PositionDelete.md) | Delete a position.  
[PositionDeleteByTicket](Positions/PositionDeleteByTicket.md) | Delete a position by ticket.  
[PositionDeleteBatch](Positions/PositionDeleteBatch.md) | Delete positions from the server database in bulk.  
[PositionBackupList](Positions/PositionBackupList.md) | Request the dates of backup databases of positions for the specified time range.  
[PositionBackupRequest](Positions/PositionBackupRequest.md) | Request an array of positions from a backup database.  
[PositionBackupRestore](Positions/PositionBackupRestore.md) | Restore a position from a backup database.  
[PositionCheck](Positions/PositionCheck.md) | Check the correctness of a client's positions based on the history of deals.  
[PositionFix](Positions/PositionFix.md) | Correct a client's positions based on the history of his deals.  
[PositionSplit](Positions/PositionSplit.md) | Split trading positions.
