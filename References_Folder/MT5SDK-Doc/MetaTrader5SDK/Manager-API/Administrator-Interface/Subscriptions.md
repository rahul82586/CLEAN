# Subscriptions

With the "Subscriptions" service, you can offer additional paid services to traders directly in the client terminals. For example, you can sell subscriptions for high-quality market data from well-known providers, offer personal manager services to assist traders in understanding the basics of trading, deliver one-time services such as position transferring or currency conversion, and much more. For further details, please read the [MetaTrader 5 Administrator Help](https://support.metaquotes.net/en/docs/mt5/platform/administration/subscriptions).

The functions described in this section enable the management of subscriptions on traders' accounts:

Function | Purpose  
---|---  
[SubscriptionCreate](Subscriptions/SubscriptionCreate.md) | Create a subscription object.  
[SubscriptionCreateArray](Subscriptions/SubscriptionCreateArray.md) | Create an object of the subscriptions array.  
[SubscriptionJoin](Subscriptions/SubscriptionJoin.md) | Add a subscription for a user.  
[SubscriptionJoinBatch](Subscriptions/SubscriptionJoinBatch.md) | Bulk adding of subscriptions for users.  
[SubscriptionCancel](Subscriptions/SubscriptionCancel.md) | Cancel a subscription for a user.  
[SubscriptionCancelBatch](Subscriptions/SubscriptionCancelBatch.md) | Bulk canceling of user subscriptions.  
[SubscriptionUpdate](Subscriptions/SubscriptionUpdate.md) | Edit a user subscription in the server database.  
[SubscriptionUpdateBatch](Subscriptions/SubscriptionUpdateBatch.md) | Bulk change of user subscriptions in the server database.  
[SubscriptionUpdateBatchArray](Subscriptions/SubscriptionUpdateBatchArray.md) | Bulk change of user subscriptions in the server database.  
[SubscriptionDelete](Subscriptions/SubscriptionDelete.md) | Delete a user subscription from the server database.  
[SubscriptionDeleteBatch](Subscriptions/SubscriptionDeleteBatch.md) | Delete a user subscription from the server database in bulk.  
[SubscriptionRequest](Subscriptions/SubscriptionRequest.md) | Request all user subscriptions from the server.  
[SubscriptionRequestByID](Subscriptions/SubscriptionRequestByID.md) | Request a subscription from the server by ID.  
[SubscriptionRequestByIDs](Subscriptions/SubscriptionRequestByIDs.md) | Request subscriptions from the server by a list of IDs.  
[SubscriptionRequestByGroup](Subscriptions/SubscriptionRequestByGroup.md) | Request subscriptions from the server by a client group.  
[SubscriptionRequestByLogins](Subscriptions/SubscriptionRequestByLogins.md) | Request subscriptions from the server by a list of logins.  
[SubscriptionHistoryCreate](Subscriptions/SubscriptionHistoryCreate.md) | Create a subscription action object.

[SubscriptionHistoryUpdate](Subscriptions/SubscriptionHistoryUpdate.md) | Edit a user subscription action in the server database.  
[SubscriptionHistoryUpdateBatch](Subscriptions/SubscriptionHistoryUpdateBatch.md) | Bulk change of user subscription actions in the server database.  
[SubscriptionHistoryUpdateBatchArray](Subscriptions/SubscriptionHistoryUpdateBatchArray.md) | Bulk change of user subscription actions in the server database.  
[SubscriptionHistoryDelete](Subscriptions/SubscriptionHistoryDelete.md) | Delete a user subscription action from the server database.  
[SubscriptionHistoryDeleteBatch](Subscriptions/SubscriptionHistoryDeleteBatch.md) | Delete a batch of user subscription actions from the server database.

[SubscriptionHistoryRequestByID](Subscriptions/SubscriptionHistoryRequestByID.md) | Request a subscription action from the server by its identifier.

[SubscriptionHistoryRequestByLogins](Subscriptions/SubscriptionHistoryRequestByLogins.md) | Request subscription actions from the server by a list of logins.
