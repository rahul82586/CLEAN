# Connecting to the Server

This section contains descriptions of methods for connecting and disconnecting an application from the server. The application is connected to the platform in one of the [pumping mode](Connection-to-the-Server/Pumping-Modes.md), which indicates what information the application will continuously receive from the server.

Method | Purpose  
---|---  
[Connect](Connection-to-the-Server/Connect.md) | Connect to the trading platform.  
[Disconnect](Connection-to-the-Server/Disconnect.md) | Disconnect from the trading platform.  
[Subscribe](Connection-to-the-Server/Subscribe.md) | Subscribe to common events of the [IMTAdminAPI](../Administrator-Interface.md).  
[Unsubscribe](Connection-to-the-Server/Unsubscribe.md) | Unsubscribe from common events of the [IMTAdminAPI](../Administrator-Interface.md).  
[ProxySet](Connection-to-the-Server/ProxySet.md) | Set parameters of connection to the trading platform through a proxy server.
