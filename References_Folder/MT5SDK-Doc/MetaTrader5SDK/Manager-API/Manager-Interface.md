# Manager Interface IMTManagerAPI

The IMTManagerAPI interface provides access to the command of the MetaTrader 5 Manager Terminal. Using this interface in an application, you can process trade requests that arrive at the trade server, work with a database of users and the price stream.

> To be able to use the IMTManagerAPI interface, a manager account that is used for [connecting to the server](Manager-Interface/Connection-to-the-Server/Connect.md) must have the "Connect using MetaTrader 5 Manager" permission ([IMTConManager::RIGHT_MANAGER (#enmanagerrights)](../Configuration-Interfaces/Managers/IMTConManager/Enumerations.md#enmanagerrights)).
