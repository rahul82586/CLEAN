# Mail Database Functions

Using the functions, you can create and send news, as well as subscribe and unsubscribe from events with changes in the news database.

The following functions are available for working with news:

Function | Purpose  
---|---  
[NewsCreate](News-Database/NewsCreate.md) | Create an object of a news item.  
[NewsSubscribe](News-Database/NewsSubscribe.md) | Subscribe to events and hooks associated with changes in the news database.  
[NewsUnsubscribe](News-Database/NewsUnsubscribe.md) | Undubscribe from events and hooks associated with changes in the news database.  
[NewsTotal](News-Database/NewsTotal.md) | Get the total number of news items received by the manager.  
[NewsNext](News-Database/NewsNext.md) | Get the news item received by the manager.  
[NewsBodyRequest](News-Database/NewsBodyRequest.md) | Get the body of the news item received by the manager.  
[NewsSend](News-Database/NewsSend.md) | Send news.
