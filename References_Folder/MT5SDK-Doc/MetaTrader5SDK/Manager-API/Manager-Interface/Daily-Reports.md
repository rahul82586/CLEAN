# Daily Report Functions

Functions described in this section allow requesting [daily reports](../../Database-Interfaces/Trade/Daily-Reports.md) of users from the server. The following functions for requesting daily reports are available:

Function | Purpose  
---|---  
[DailyCreate](Daily-Reports/DailyCreate.md) | Create an object of a daily report.  
[DailyCreateArray](Daily-Reports/DailyCreateArray.md) | Create an object of the array of daily reports.  
[DailyRequest](Daily-Reports/DailyRequest.md) | Get an array of daily reports by the login and date range.  
[DailyRequestByLogins](Daily-Reports/DailyRequestByLogins.md) | Get an array of daily reports by the list of logins and date range.  
[DailyRequestByGroup](Daily-Reports/DailyRequestByGroup.md) | Get an array of daily reports by groups and date range.  
[DailyRequestLight](Daily-Reports/DailyRequestLight.md) | Get an array of lightweight daily reports by the login and date range. Unlike full daily reports, lightweight reports do not include open client orders and positions.  
[DailyRequestLightByLogins](Daily-Reports/DailyRequestLightByLogins.md) | Get an array of lightweight daily reports by the list of logins and date range.  
[DailyRequestLightByGroup](Daily-Reports/DailyRequestLightByGroup.md) | Get an array of lightweight daily reports by groups and date range.
