# Operations with Connection

This section describes methods for working with Manager API network connection. The following methods are available:

Method | Purpose  
---|---  
[NetworkRescan](Operations-with-Connection/NetworkRescan.md) | Forced launch of scanning for access points and receiving the scanning results.  
[NetworkBytesSent](Operations-with-Connection/NetworkBytesSent.md) | Receive the number of bytes sent to the server via Manager API.  
[NetworkBytesRead](Operations-with-Connection/NetworkBytesRead.md) | Receive the number of bytes accepted from the server via Manager API.  
[NetworkServer](Operations-with-Connection/NetworkServer.md) | Receive the name of the server Manager API is currently connected to.  
[NetworkAddress](Operations-with-Connection/NetworkAddress.md) | Receive IP address of the server Manager API is currently connected to.
