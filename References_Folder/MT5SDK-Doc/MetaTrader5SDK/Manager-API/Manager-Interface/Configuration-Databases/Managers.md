# Configuration of Managers

Functions from this section allow obtaining the description of own manager account, including access permissions for certain data and platform functions.

Function | Purpose  
---|---  
[ManagerCreate](Managers/ManagerCreate.md) | Create a manager configuration object.  
[ManagerAccessCreate](Managers/ManagerAccessCreate.md) | Create an object of access list configuration by IP addresses for a manager.  
[ManagerReportCreate](Managers/ManagerReportCreate.md) | Create an object for the manager's permission to access the report.  
[ManagerCurrent](Managers/ManagerCurrent.md) | Get the configuration of the current manager account.
