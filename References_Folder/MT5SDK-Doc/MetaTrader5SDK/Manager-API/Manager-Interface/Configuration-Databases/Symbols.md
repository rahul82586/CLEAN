# Configuration of Symbols

Use these functions to obtain symbol settings, as well to subscribe and unsubscribe from events associated with their change.

The following functions are available for working with symbol settings:

Function | Purpose  
---|---  
[SymbolCreate](Symbols/SymbolCreate.md) | Create an object of the symbol configuration.  
[SymbolCreateArray](Symbols/SymbolCreateArray.md) | Create a symbols array object.  
[SymbolSessionCreate](Symbols/SymbolSessionCreate.md) | Create an object of configuration of a trading or quoting session of the symbol.  
[SymbolSubscribe](Symbols/SymbolSubscribe.md) | Subscribe to events associated with the configuration of symbols.  
[SymbolUnsubscribe](Symbols/SymbolUnsubscribe.md) | Unsubscribe from events associated with the configuration of symbols.  
[SymbolUpdate](Symbols/SymbolUpdate.md) | Update symbol configuration.  
[SymbolUpdateBatch](Symbols/SymbolUpdateBatch.md) | Update multiple symbol configurations.  
[SymbolTotal](Symbols/SymbolTotal.md) | The total number of symbol configurations available in the platform.  
[SymbolNext](Symbols/SymbolNext.md) | Get the symbol configuration by the index.  
[SymbolGet](Symbols/SymbolGet.md) | Get a symbol configuration or an individual configuration of a symbol for a group by the name of the symbol.  
[SymbolRequest](Symbols/SymbolRequest.md) | Request a symbol configuration from a server by the name.  
[SymbolRequestArray](Symbols/SymbolRequestArray.md) | Request from the server an array of symbols by mask.  
[SymbolExist](Symbols/SymbolExist.md) | Check the availability of a symbol for a specified [group](../../../Configuration-Interfaces/Groups.md) of clients.
