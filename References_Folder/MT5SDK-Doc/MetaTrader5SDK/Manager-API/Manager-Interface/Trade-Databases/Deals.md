# Deals

Using the functions, you can view a server database of deals. The following functions are available for working with deals:

Function | Purpose  
---|---  
[DealCreate](Deals/DealCreate.md) | Create an object of a deal.  
[DealCreateArray](Deals/DealCreateArray.md) | Create an object of the array of deals.  
[DealSubscribe](Deals/DealSubscribe.md) | Subscribe to events associated with changes in the database of deals.  
[DealUnsubscribe](Deals/DealUnsubscribe.md) | Unsubscribe from the events associated with changes in the database of deals.  
[DealRequest](Deals/DealRequest.md) | Get a deal by a ticket and login.  
[DealRequestByGroup](Deals/DealRequestByGroup.md) | Receive deals related to a group of accounts.  
[DealRequestByGroupSymbol](Deals/DealRequestByGroupSymbol.md) | Get deals by group and symbol.  
[DealRequestByLogins](Deals/DealRequestByLogins.md) | Receive deals by the list of logins.  
[DealRequestByLoginsSymbol](Deals/DealRequestByLoginsSymbol.md) | Get deals by a list of logins and symbol.  
[DealRequestByTickets](Deals/DealRequestByTickets.md) | Receive deals by the list of tickets.  
[DealRequestPage](Deals/DealRequestPage.md) | Get client deals with a paged output.  
[DealAdd](Deals/DealAdd.md) | Add a deal to the server database.  
[DealAddBatch](Deals/DealAddBatch.md) | Add a batch of deals to the server database.  
[DealAddBatchArray](Deals/DealAddBatchArray.md) | Add a batch of deals to the server database.  
[DealUpdate](Deals/DealUpdate.md) | Update a deal.  
[DealUpdateBatch](Deals/DealUpdateBatch.md) | Update deals in a server database in bulk.  
[DealUpdateBatchArray](Deals/DealUpdateBatchArray.md) | Update deals in a server database in bulk.  
[DealDelete](Deals/DealDelete.md) | Delete a deal.  
[DealDeleteBatch](Deals/DealDeleteBatch.md) | Delete deals from the server database in bulk.  
[DealPerform](Deals/DealPerform.md) | Perform a deal on the client's account. This method performs a market buy or sell operation on the account as if it were performed by the client through the terminal.  
[DealPerformBatch](Deals/DealPerformBatch.md) | Perform multiple deals on the client's account. This method performs market buy or sell operations on the account as if they were performed by the client through the terminal.  
[DealPerformBatchArray](Deals/DealPerformBatchArray.md) | Perform multiple deals on the client's account. This method performs market buy or sell operations on the account as if they were performed by the client through the terminal.
