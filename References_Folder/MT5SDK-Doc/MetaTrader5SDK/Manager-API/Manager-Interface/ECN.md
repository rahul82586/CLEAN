# ECN

MetaTrader 5 API provides access to [built-in ECN](https://support.metaquotes.net/en/docs/mt5/platform/administration/ecn) databases. Functions from these section enable the detailed analysis of the current matching queue and history, of operations with liquidity providers and other data.

Function | Purpose  
---|---  
[ECNCreateMatching](../Administrator-Interface/ECN/CreateMatching.md) | Create a matching order object.  
[ECNCreateMatchingArray](../Administrator-Interface/ECN/CreateMatchingArray.md) | Create an array of matching order objects.  
[ECNCreateFilling](../Administrator-Interface/ECN/CreateFilling.md) | Create a filling order object.  
[ECNCreateFillingArray](../Administrator-Interface/ECN/CreateFillingArray.md) | Create an array of filling objects.  
[ECNCreateProvider](../Administrator-Interface/ECN/CreateProvider.md) | Create an object of a provider via which orders are executed.  
[ECNCreateProviderArray](../Administrator-Interface/ECN/CreateProviderArray.md) | Create an object of the array of providers via which orders are executed.  
[ECNCreateHistoryMatching](../Administrator-Interface/ECN/CreateHistoryMatching.md) | Create an object of a matching order from history.  
[ECNCreateHistoryMatchingArray](../Administrator-Interface/ECN/CreateHistoryMatchingArray.md) | Create an array of matching order objects from history.  
[ECNCreateHistoryFilling](../Administrator-Interface/ECN/CreateHistoryFilling.md) | Create an object of a filling order from history.  
[ECNCreateHistoryFillingArray](../Administrator-Interface/ECN/CreateHistoryFillingArray.md) | Create an array of filling order objects from history.  
[ECNCreateHistoryDeal](../Administrator-Interface/ECN/CreateHistoryDeal.md) | Create an object of a deal from the ECN history.  
[ECNCreateHistoryDealArray](../Administrator-Interface/ECN/CreateHistoryDealArray.md) | Create an object of an array of deals from the ECN history.  
[ECNRequestByGroup](../Administrator-Interface/ECN/RequestByGroup.md) | Request the current state of matching for the specified client groups.  
[ECNRequestByLogins](../Administrator-Interface/ECN/RequestByLogins.md) | Request the current state of matching for the specified logins.  
[ECNRequestByTickets](../Administrator-Interface/ECN/RequestByTickets.md) | Request the current state of matching for the specified order tickets.  
[ECNRequestHistoryByGroup](../Administrator-Interface/ECN/RequestHistoryByGroup.md) | Request the matching history for the specified client groups.  
[ECNRequestHistoryByLogins](../Administrator-Interface/ECN/RequestHistoryByLogins.md) | Request the matching history for the specified logins.  
[ECNRequestHistoryByTickets](../Administrator-Interface/ECN/RequestHistoryByTickets.md) | Request the matching history for the specified order tickets.
