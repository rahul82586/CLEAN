# IMTReportDashboardHtml

The IMTDataset interface is used for working with dashboard HTML content. It contains the following methods:

Method | Purpose  
---|---  
[Assign](IMTReportDashboardHtml/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTReportDashboardHtml/Clear.md) | Clear an object.  
[Write](IMTReportDashboardHtml/Write.md) | Output a formatted sting into an HTML page.  
[WriteString](IMTReportDashboardHtml/WriteString.md) | Output an unformatted string into an HTML page (faster output).  
[WriteSafe](IMTReportDashboardHtml/WriteSafe.md) | Output a string into HTML with HTML service symbols screening.  
[WriteChart](IMTReportDashboardHtml/WriteChart.md) | Display a chart on a dashboard.  
[TplLoad](IMTReportDashboardHtml/TplLoad.md) | Load a template from the submitted line.  
[TplLoadFile](IMTReportDashboardHtml/TplLoadFile.md) | Load a template from a file.  
[TplLoadResource](IMTReportDashboardHtml/TplLoadResource.md) | Load a template from a resource.  
[TplNext](IMTReportDashboardHtml/TplNext.md) | Get the next macros (predetermined tag) from a template for processing.  
[TplProcess](IMTReportDashboardHtml/TplProcess.md) | Set the feature of the processing of all tags inside the current macros (predetermined tag).
