# Report Parameters

To manage generated reports parameters, the following functions are available:

Function | Purpose  
---|---  
[ParamCreate](Report-Parameters/ParamCreate.md) | Create an object of a report parameter.  
[ParamTotal](Report-Parameters/ParamTotal.md) | Get the number of parameters set by a manager during report generation.  
[ParamGet](Report-Parameters/ParamGet.md) | Get a report parameter set in a manager terminal by its name.  
[ParamNext](Report-Parameters/ParamNext.md) | Get a report parameter set from a manager terminal by its position.  
[ParamLogins](Report-Parameters/ParamLogins.md) | Get an array of the logins, for which a report from a manager terminal is requested.  
[ParamFrom](Report-Parameters/ParamFrom.md) | Get the beginning of the time range set in a manager terminal, for which a report is generated.  
[ParamTo](Report-Parameters/ParamTo.md) | Get the end of the time range set in a manager terminal, for which a report is generated.  
[ParamGroups](Report-Parameters/ParamGroups.md) | Get the "Groups" parameter value line set in a manager terminal.  
[ParamSymbols](Report-Parameters/ParamSymbols.md) | Get the "Symbols" parameter value line set in a manager terminal.  
[ParamIEVersion](Report-Parameters/ParamIEVersion.md) | Get the Internet Explorer version installed on the computer with the manager terminal requesting a report.  
[ParamScreenWidth](Report-Parameters/ParamScreenWidth.md) | Get a screen resolution by width on the computer with the manager terminal requesting a report.  
[ParamScreenHeight](Report-Parameters/ParamScreenHeight.md) | Get a screen resolution by height on the computer with the manager terminal requesting a report.
