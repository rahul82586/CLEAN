# IMTReportAPI::ParamFrom

Get the head of the time range set in a manager terminal, for which a report is generated.
    
    
    INT64  IMTReportAPI::ParamFrom()

### Return Value

The head of the time range in seconds that have elapsed since 01.01.1970.
