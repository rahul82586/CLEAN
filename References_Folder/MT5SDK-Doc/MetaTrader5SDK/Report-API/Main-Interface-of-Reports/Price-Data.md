# Price Data Functions

Functions described in this section allow requesting price data in the form of ticks and 1-minute bars from the history server.

Function | Purpose  
---|---  
[TickGet](Price-Data/TickGet.md) | Get quotes for a symbol in the specified time range.  
[TickLast](Price-Data/TickLast.md) | Get the last quote for the specified symbol.  
[TickStat](Price-Data/TickStat.md) | Get statistical information about quotes for the specified symbol.  
[TickHistoryGetRaw](Price-Data/TickHistoryGetRaw.md) | Get raw quotes (not processed prices in accordance with the configuration of the symbol) for a symbol in the specified time range.  
[TickHistoryGet](Price-Data/TickHistoryGet.md) | Get the history of quotes processed in accordance with the symbol configuration in the specified time range.  
[ChartHistoryGet](Price-Data/ChartHistoryGet.md) | Request minute bars for a symbol.
