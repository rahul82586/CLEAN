# Data set

Data sets are used for preparing source data for the creation of [dashboards](../Dashboards.md) and [tabular reports](../Tabular-Reports.md). Information in a set is stored as a table with a set of columns and rows and a special summary row.

The following functions are available for working with data sets:

Function | Purpose  
---|---  
[DatasetAppend](Dataset/Append.md) | Add a data set to a dashboard.  
[DatasetClear](Dataset/Clear.md) | Delete all data sets from a dashboard.  
[DatasetDelete](Dataset/Delete.md) | Delete a data set from a dashboard.  
[DatasetTotal](Dataset/Total.md) | Get the number of data sets in a dashboard.  
[DatasetNext](Dataset/Next.md) | Get the data set description based in the index.  
[DatasetRequestCreate](Dataset/RequestCreate.md) | Create a data request object.
