# User Functions

The functions allow receiving the data on users and their trade accounts from a trade server database. The following functions are available for working with users:

Functions | Purpose  
---|---  
[UserCreate](Users/UserCreate.md) | Create an object of a client record.  
[UserCreateAccount](Users/UserCreateAccount.md) | Create an object of a client's trading account.  
[UserGet](Users/UserGet.md) | Get a client record by the login.  
[UserGetLight](Users/UserGetLight.md) | Get the client record brief description.  
[UserLogins](Users/UserLogins.md) | Returns an array of logins of the clients who are included in the specified group.  
[UserAccountGet](Users/UserAccountGet.md) | Get client trading account by a login.  
[UserSelect](Users/UserSelect.md) | Request accounts from a database according to specified criteria.  
[UserAccountSelect](Users/UserAccountSelect.md) | Request trading account from a database according to specified criteria.  
[ClientSelect](Users/ClientSelect.md) | Request clients from a database according to specified criteria.
