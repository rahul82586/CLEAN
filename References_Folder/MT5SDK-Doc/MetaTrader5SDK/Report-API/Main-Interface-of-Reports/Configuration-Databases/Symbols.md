# Configuration of Symbols

To get the symbols configuration, the following functions are available:

Function | Purpose  
---|---  
[SymbolCreate](Symbols/SymbolCreate.md) | Create an object of the symbol configuration.  
[SymbolSessionCreate](Symbols/SymbolSessionCreate.md) | Create an object of configuration of a trading or quoting session of the symbol.  
[SymbolTotal](Symbols/SymbolTotal.md) | The total number of symbol configurations available in the platform.  
[SymbolNext](Symbols/SymbolNext.md) | Get the symbol configuration by the index.  
[SymbolGet](Symbols/SymbolGet.md) | Get the symbol configuration.  
[SymbolGetLight](Symbols/SymbolGetLight.md) | Get an eased configuration of a symbol.  
[SymbolExist](Symbols/SymbolExist.md) | Check the availability of a symbol for a specified group of clients.
