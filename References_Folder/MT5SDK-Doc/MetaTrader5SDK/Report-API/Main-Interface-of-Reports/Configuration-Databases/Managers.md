# Configuration of Managers

To get managers configuration, the following functions are available:

Function | Purpose  
---|---  
[ManagerCreate](Managers/ManagerCreate.md) | Create a manager configuration object.  
[ManagerAccessCreate](Managers/ManagerAccessCreate.md) | Create an object of configuration of an access list by IP addresses for a manager.  
[ManagerReportCreate](Managers/ManagerReportCreate.md) | Create an object for the manager's permission to access the report.  
[ManagerCurrent](Managers/ManagerCurrent.md) | Get the configuration of the manager who requested report generation from the manager terminal.  
[ManagerTotal](Managers/ManagerTotal.md) | The total number of manager configurations available in the platform.  
[ManagerNext](Managers/ManagerNext.md) | Get a manager configuration with the specified index.  
[ManagerGet](Managers/ManagerGet.md) | Get a manager configuration with the specified login.
