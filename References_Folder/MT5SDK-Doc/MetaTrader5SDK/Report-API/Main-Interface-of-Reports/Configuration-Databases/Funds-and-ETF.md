# Funds and ETFs

MetaTrader 5 enables the automation of fund operations. This includes investor and manager operations, investment management, access to charts and reports: For more details, please read the [MetaTrader 5 Administrator Help](https://support.metaquotes.net/en/docs/mt5/platform/administration/fund_etf).

The functions described in this section enable the management of fund settings:

Function | Purpose  
---|---  
[FundCreate](Funds-and-ETF/FundCreate.md) | Create a fund configuration object.  
[FundAccountCreate](Funds-and-ETF/FundAccountCreate.md) | Create a fund manager object.  
[FundInvestorCreate](Funds-and-ETF/FundInvestorCreate.md) | Create a fund investor object.  
[FundTotal](Funds-and-ETF/FundTotal.md) | Get the total number of fund configurations available in the platform.  
[FundNext](Funds-and-ETF/FundNext.md) | Get a fund configuration by index.  
[FundGet](Funds-and-ETF/FundGet.md) | Get a fund configuration by name.
