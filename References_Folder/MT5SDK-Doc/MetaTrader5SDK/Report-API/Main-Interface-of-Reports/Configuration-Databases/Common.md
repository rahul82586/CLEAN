# Common Configuration

The following functions for obtaining common system settings are available:

Function | Purpose  
---|---  
[CommonCreate](Common/Create.md) | Create a common platform configuration object.  
[CommonCreateAllocation](Common/CreateAllocation.md) | Create an account allocation configuration object.  
[CommonCreateAgreement](Common/CreateAgreement.md) | Create an agreement object for an account allocation configuration.  
[CommonGet](Common/Get.md) | Get the common platform configuration.
