# Time Configuration

To get time configuration, the following functions are available:

Function | Purpose  
---|---  
[TimeCreate](Time/Create.md) | Create an object of the time configuration.  
[TimeCurrent](Time/Current.md) | Get the current trading time.  
[TimeGeneration](Time/Generation.md) | Get the time of the beginning of the current report generation.  
[TimeGet](Time/Get.md) | Get the time configuration.
