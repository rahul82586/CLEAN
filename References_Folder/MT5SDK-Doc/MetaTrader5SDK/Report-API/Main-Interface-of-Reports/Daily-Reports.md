# Daily Reports Database Functions

The functions described in this section allow to observe the daily reports generated by the MetaTrader 5 trade server. The following functions are available for working with a daily reports base:

Function | Purpose  
---|---  
[DailyCreate](Daily-Reports/DailyCreate.md) | Create an object of a daily report.  
[DailyCreateArray](Daily-Reports/DailyCreateArray.md) | Create an object of the array of daily reports.  
[DailyGet](Daily-Reports/DailyGet.md) | Get daily reports.  
[DailyGetLight](Daily-Reports/DailyGetLight.md) | Get eased daily reports.  
[DailySelect](Daily-Reports/DailySelect.md) | Request daily reports from a database according to specified criteria.
