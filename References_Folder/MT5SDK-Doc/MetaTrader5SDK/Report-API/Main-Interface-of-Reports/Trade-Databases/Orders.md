# Orders

The functions allow to observe a server trading orders base. The following functions are available for this purpose:

Function | Purpose  
---|---  
[OrderCreate](Orders/OrderCreate.md) | Create an object of a trade order.  
[OrderCreateArray](Orders/OrderCreateArray.md) | Create an object of the array of orders.  
[OrderGet](Orders/OrderGet.md) | Gets open orders of a client.  
[OrderSelect](Orders/OrderSelect.md) | Request open orders from a database according to specified criteria.  
[HistoryGet](Orders/HistoryGet.md) | Get closed orders of a client.  
[HistorySelect](Orders/HistorySelect.md) | Request closed orders from a database according to specified criteria.
