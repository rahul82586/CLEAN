# Positions

The functions allow to observe a database of positions on a server. The following functions are available for this purpose:

Function | Purpose  
---|---  
[PositionCreate](Positions/PositionCreate.md) | Create an object of a trade position.  
[PositionCreateArray](Positions/PositionCreateArray.md) | Create an object of the array of trade positions.  
[PositionGet](Positions/PositionGet.md) | Get clients positions.  
[PositionGetByTicket](Positions/PositionGetByTicket.md) | Get a trade position by the ticket.  
[PositionSelect](Positions/PositionSelect.md) | Request trading positions from a database according to specified criteria.
