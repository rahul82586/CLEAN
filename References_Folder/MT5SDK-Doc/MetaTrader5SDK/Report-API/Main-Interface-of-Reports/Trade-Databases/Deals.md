# Deals

The function allow observing a database of deals on a trade server. The following functions are available for working with deals:

Function | Purpose  
---|---  
[DealCreate](Deals/DealCreate.md) | Create an object of a deal.  
[DealCreateArray](Deals/DealCreateArray.md) | Create an object of the array of deals.  
[DealGet](Deals/DealGet.md) | Get clients deals.  
[DealSelect](Deals/DealSelect.md) | Request deals from a database according to specified criteria.
