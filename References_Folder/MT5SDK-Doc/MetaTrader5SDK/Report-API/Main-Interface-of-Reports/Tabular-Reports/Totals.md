# Totals Functions

To manage a table totals row, the following functions are available:

Function | Purpose  
---|---  
[TableSummaryCreate](Totals/TableSummaryCreate.md) | Create an object of a totals row cell.  
[TableSummaryClear](Totals/TableSummaryClear.md) | Clear all total records.  
[TableSummaryAdd](Totals/TableSummaryAdd.md) | Add a totals row cell into a table.  
[TableSummaryDelete](Totals/TableSummaryDelete.md) | Delete a cell in a table totals row by its index.  
[TableSummaryNext](Totals/TableSummaryNext.md) | Get the cells of a table totals row by its index.  
[TableSummaryTotal](Totals/TableSummaryTotal.md) | Get the total amount of totals cells in a table.
