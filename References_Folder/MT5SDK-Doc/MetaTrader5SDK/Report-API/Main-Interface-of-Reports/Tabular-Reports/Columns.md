# Columns Functions

The following functions for managing columns are available:

Function | Purpose  
---|---  
[TableColumnCreate](Columns/TableColumnCreate.md) | A column object creation.  
[TableColumnClear](Columns/TableColumnClear.md) | Clear table columns description.  
[TableColumnAdd](Columns/TableColumnAdd.md) | Add a column description to a table end.  
[TableColumnDelete](Columns/TableColumnDelete.md) | Delete a column description from a table by index.  
[TableColumnTotal](Columns/TableColumnTotal.md) | Get the number of columns in a table.  
[TableColumnSize](Columns/TableColumnSize.md) | Get a total size of one table row in bytes.  
[TableColumnNext](Columns/TableColumnNext.md) | Get a column description by index.
