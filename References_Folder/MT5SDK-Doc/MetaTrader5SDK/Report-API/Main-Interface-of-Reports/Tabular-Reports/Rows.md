# Rows Functions

The following functions for managing rows are available:

Function | Purpose  
---|---  
[TableRowClear](Rows/TableRowClear.md) | Delete the contents of a whole table.  
[TableRowWrite](Rows/TableRowWrite.md) | Add (output) one record to a table.  
[TableRowTotal](Rows/TableRowTotal.md) | Get the number of rows in a table.
