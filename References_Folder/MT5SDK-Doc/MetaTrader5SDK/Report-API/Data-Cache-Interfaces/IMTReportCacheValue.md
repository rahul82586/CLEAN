# IMTReportCacheValue

IMTReportCacheValue is the [data cache](../Main-Interface-of-Reports/Data-cache.md) key description interface. It is used for working with the cache values and for iteration between keys.

Method | Purpose  
---|---  
[Release](IMTReportCacheValue/Release.md) | Delete the current object.  
[Key](IMTReportCacheValue/Key.md) | Get a key.  
[Data](IMTReportCacheValue/Data.md) | Get the key value.  
[Size](IMTReportCacheValue/Size.md) | Get the value of the key size type.  
[Next](IMTReportCacheValue/Next.md) | Go to the next key.
