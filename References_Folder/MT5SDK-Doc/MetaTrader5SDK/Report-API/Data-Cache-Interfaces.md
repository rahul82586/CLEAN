# Data Cache Interfaces

The interfaces described in this section are used for working with the [data cache](Main-Interface-of-Reports/Data-cache.md):

  * [IMTReportCache](Data-Cache-Interfaces/IMTReportCache.md) contains methods for working with the cache, i.e. for data reading and writing.
  * [IMTReportCacheValue](Data-Cache-Interfaces/IMTReportCacheValue.md) creates methods for working with the cache value and iterating between values.
  * [IMTReportCacheKeySet](Data-Cache-Interfaces/IMTReportCacheKeySet.md) creates methods for working with the sets of data cache keys.
