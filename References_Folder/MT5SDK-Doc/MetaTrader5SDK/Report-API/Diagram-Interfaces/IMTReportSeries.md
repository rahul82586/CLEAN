# IMTReportSeries

The IMTReportSeries interface is used for working with data series for creating charts. It contains the following methods:

Method | Purpose  
---|---  
[Release](IMTReportSeries/Release.md) | Delete the current object.  
[Assign](IMTReportSeries/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTReportSeries/Clear.md) | Clear an object.  
[Title](IMTReportSeries/Title.md) | Get and set a data series header.  
[Type](IMTReportSeries/Type.md) | Get and set a data series type.  
[Flags](IMTReportSeries/Flags.md) | Get and set data series flags.  
[Color](IMTReportSeries/Color.md) | Get the color used for a data series display on a chart.  
[Tooltip](IMTReportSeries/Tooltip.md) | Get and set a tooltip text for a series.  
[ValueClear](IMTReportSeries/ValueClear.md) | Clear all series values.  
[ValueTotal](IMTReportSeries/ValueTotal.md) | Get the total amount of values in a series.  
[ValueAdd](IMTReportSeries/ValueAdd.md) | Add a value to a series.  
[ValueAddInt](IMTReportSeries/ValueAddInt.md) | Add integer value to a series.  
[ValueAddDouble](IMTReportSeries/ValueAddDouble.md) | Add a value with a floating point to a series.  
[ValueUpdate](IMTReportSeries/ValueUpdate.md) | Change the value at the indicated series position.  
[ValueUpdateInt](IMTReportSeries/ValueUpdateInt.md) | Change the integer value at the indicated series position.  
[ValueUpdateDouble](IMTReportSeries/ValueUpdateDouble.md) | Change the value with a floating point at the indicated series position.  
[ValueNext](IMTReportSeries/ValueNext.md) | Get the value at the indicated series position.  
[ValueNextInt](IMTReportSeries/ValueNextInt.md) | Get the integer value at the indicated series position.  
[ValueNextDouble](IMTReportSeries/ValueNextDouble.md) | Get the value with a floating point at the indicated series position.  
[ValueShift](IMTReportSeries/ValueShift.md) | Shift a value in a series.  
[ValueDelete](IMTReportSeries/ValueDelete.md) | Delete the value at the indicated series position.  
[ValueDescription](IMTReportSeries/ValueDescription.md) | Get and set a description for a series value.  
  
The IMTReportSeries interface contains the following enumerations:

Enumeration | Purpose  
---|---  
[EnSeriesType (#enseriestype)](IMTReportSeries/Enumerations.md#enseriestype) | Types of series.  
[EnSeriesFlags (#enseriesflags)](IMTReportSeries/Enumerations.md#enseriesflags) | Flags of series.
