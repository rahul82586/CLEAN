# IMTReportChart

The IMTReportChart interface is used for working with charts. It contains the following methods:

Method | Purpose  
---|---  
[Release](IMTReportChart/Release.md) | Delete the current object.  
[Assign](IMTReportChart/Assign.md) | Assign a passed object to the current one.  
[Clear](IMTReportChart/Clear.md) | Clear an object.  
[Title](IMTReportChart/Title.md) | Get and set a chart header.  
[Type](IMTReportChart/Type.md) | Get and set a chart type.  
[Digits](IMTReportChart/Digits.md) | Get and set the number of decimal places for formatting the values shown in a chart.  
[Flags](IMTReportChart/Flags.md) | Get and set a chart flags.  
[BarHeight](IMTReportChart/BarHeight.md) | Get and set the chart bar height.  
[PieceTooltip](IMTReportChart/PieceTooltip.md) | Get and set a pie chart element tooltip.  
[PieceDescription](IMTReportChart/PieceDescription.md) | Get and set a pie chart element description.  
[SeriesClear](IMTReportChart/SeriesClear.md) | Delete all chart series.  
[SeriesAdd](IMTReportChart/SeriesAdd.md) | Add data series to a chart.  
[SeriesAddCopy](IMTReportChart/SeriesAddCopy.md) | Add a data series copy to a chart.  
[SeriesDelete](IMTReportChart/SeriesDelete.md) | Delete an object of a data series by its position.  
[SeriesDetach](IMTReportChart/SeriesDetach.md) | Detach a data series object from a chart.  
[SeriesUpdate](IMTReportChart/SeriesUpdate.md) | Change a data series at the specified position of a chart.  
[SeriesShift](IMTReportChart/SeriesShift.md) | Change data series position in a chart.  
[SeriesTotal](IMTReportChart/SeriesTotal.md) | Get a number of data series objects in a chart.  
[SeriesNext](IMTReportChart/SeriesNext.md) | Get a data series object by its position.  
  
The IMTReportChart interface contains the following enumerations:

Interface | Purpose  
---|---  
[EnChartType (#encharttype)](IMTReportChart/Enumerations.md#encharttype) | Types of charts.  
[EnChartFlags (#enchartflags)](IMTReportChart/Enumerations.md#enchartflags) | Charts display flags.
