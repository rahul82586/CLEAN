## IMTDataset::EnDataSetFlags (#endatasetflags)

Flags of tabular data for a dashboard are enumerated in IMTDataset::EnDataSetFlags.

ID | Value | Description  
DATASET_FLAG_NONE | 0x0 | No flags.  
  
The enumeration is used in the [IMTDataset::Flags](Flags.md) method.
